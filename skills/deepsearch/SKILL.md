# DeepSearch 深度搜索技能 v1.0

> 灵感来源：福尔摩斯 - 抽丝剥茧，洞察秋毫
> 核心理念：多策略、多角度、深度挖掘，不放过任何线索

## 概述

DeepSearch（深度搜索）是一种**多策略深度代码库搜索**技能，
使用多种搜索策略并行探索，确保找到所有相关代码和信息。

与普通搜索的区别：
- **普通搜索**：单一关键词匹配
- **DeepSearch**：多策略并行 + 语义理解 + 上下文关联

## 核心策略

| 策略 | 说明 | 工具 |
|------|------|------|
| 🔤 关键词搜索 | 精确匹配关键词 | Grep |
| 📁 文件名搜索 | 搜索文件名模式 | Glob |
| 🌲 AST 搜索 | 结构化代码搜索 | AST-Grep |
| 🔗 引用追踪 | 追踪符号引用 | LSP |
| 📖 语义搜索 | 理解代码意图 | AI 分析 |
| 🕸️ 依赖分析 | 追踪导入关系 | 静态分析 |

## 使用方式

### 命令格式

```bash
# 中文命令
/shensou 找到所有处理用户认证的代码

# 英文命令
/deepsearch find all authentication handling code

# 简写
/ds 认证相关代码
```

### 搜索模式

```bash
# 全面搜索（默认）
/shensou 认证模块

# 快速搜索
/shensou --quick 登录函数

# 深度搜索（最彻底）
/shensou --thorough 安全漏洞

# 指定策略
/shensou --strategy=ast,lsp 函数定义
```

## 与悟空探索的区别

| 特性 | 悟空 (探索) | DeepSearch (深搜) |
|------|------------|------------------|
| 速度 | 快速 | 较慢但更彻底 |
| 深度 | 表面扫描 | 深度挖掘 |
| 策略 | 单一策略 | 多策略并行 |
| 上下文 | 基本 | 完整依赖分析 |
| 适用场景 | 快速定位 | 全面了解 |

**选择建议**：
- 知道大概位置 → 悟空
- 需要全面了解 → DeepSearch

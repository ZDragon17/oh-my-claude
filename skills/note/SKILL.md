# Note 笔记本技能 v1.0

> 灵感来源：司马迁 - 究天人之际，通古今之变
> 核心理念：压缩抗性笔记本，重要信息不会在上下文压缩中丢失

## 概述

Note（笔记本）是一种**压缩抗性记忆系统**，
用于保存重要信息、决策、发现等，确保这些信息在长对话的上下文压缩中不会丢失。

与普通记录的区别：
- **普通消息**：可能在上下文压缩时被丢弃
- **Note 笔记**：特殊标记，压缩时优先保留

## 使用方式

### 命令格式

```bash
# 添加笔记
/biji 这个项目使用 JWT 进行认证，密钥在环境变量 JWT_SECRET 中

# 英文命令
/note remember: auth uses JWT with secret in JWT_SECRET env var

# 简写
/n 记住：数据库连接字符串在 .env 文件中
```

### 笔记操作

```bash
# 添加笔记（默认）
/biji 重要发现：API 限流设置为 100/分钟

# 查看所有笔记
/biji list

# 搜索笔记
/biji search 认证

# 删除笔记
/biji delete 3

# 清空笔记
/biji clear

# 导出笔记
/biji export --format=md
```

### 笔记分类

```bash
# 添加带分类的笔记
/biji --category=architecture 系统采用微服务架构

# 按分类查看
/biji list --category=decision

# 预设分类
# - discovery: 发现
# - decision: 决策
# - architecture: 架构
# - warning: 警告
# - todo: 待办
# - reference: 参考
```

### 高级选项

```bash
# 设置优先级
/biji --priority=high 关键：不要修改 legacy 模块

# 添加标签
/biji --tags=auth,security JWT 配置说明

# 设置过期时间
/biji --expires=7d 临时：使用 mock 服务器测试

# 保存到全局笔记
/biji --global 通用技巧：TypeScript 类型推断
```

## 自动捕获

### Remember 标签

在对话中使用 `<remember>` 标签，内容会自动保存到笔记本：

```
<remember>
这个项目的测试覆盖率要求是 80%
</remember>
```

### 关键词触发

以下关键词会触发自动笔记建议：

| 关键词 | 触发行为 |
|--------|----------|
| `重要` `important` | 建议添加高优先级笔记 |
| `记住` `remember` | 自动添加笔记 |
| `注意` `warning` | 添加警告类笔记 |
| `决定` `decided` | 添加决策类笔记 |
| `发现` `found` | 添加发现类笔记 |

## 与上下文压缩的集成

### 压缩保护机制

```
上下文压缩触发时:
1. 普通消息 → 可能被压缩摘要
2. Note 笔记 → 完整保留
3. Remember 标签内容 → 完整保留
```

### 压缩优先级

| 优先级 | 内容类型 | 压缩行为 |
|--------|----------|----------|
| 🔴 最高 | 系统提示 | 永不压缩 |
| 🟠 高 | Note 笔记 | 优先保留 |
| 🟡 中 | 代码块 | 选择性保留 |
| 🟢 低 | 普通对话 | 可压缩 |

## 最佳实践

### 什么应该记录

✅ **应该记录**：
- 关键配置信息（环境变量、密钥位置）
- 重要决策及理由
- 发现的问题和解决方案
- 架构设计决策
- 需要注意的警告
- 跨会话需要的上下文

❌ **不应该记录**：
- 临时调试信息
- 显而易见的信息
- 可以从代码推断的内容
- 一次性使用的信息

### 笔记组织建议

1. **保持简洁**: 每条笔记一个要点
2. **使用分类**: 便于后续检索
3. **定期清理**: 删除过时信息
4. **优先级标记**: 重要信息标高优先级

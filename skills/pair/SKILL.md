# AI 结对编程技能 (Pair Programming)

智能结对编程模式，让 AI 成为你的编程伙伴。

## 核心理念

> 两人编程，事半功倍。
> 智能伙伴，随时待命。

## 功能概述

### 👀 实时观察

观察你的编码行为，了解当前工作：

- 正在编辑的文件
- 代码变更模式
- 搜索和导航行为
- 编辑节奏和频率

### 💡 智能建议

在适当时机提供建议（不打断工作流）：

- 代码补全建议
- 优化建议
- 错误检测
- 测试用例建议

### 🆘 困难检测

检测到可能遇到困难时主动询问：

- 同一行频繁修改
- 频繁撤销操作
- 长时间无进展
- 频繁搜索关键词

## 工作模式

| 模式 | 介入频率 | 适合场景 |
|------|----------|----------|
| 被动 (passive) | 低 | 熟悉领域，不想被打扰 |
| 主动 (active) | 高 | 学习新技术，需要指导 |
| 安静 (quiet) | 极低 | 只需要时才帮助 |

## 使用方式

### 开始结对

```bash
/pair start
/pair start --mode active
```

### 结束结对

```bash
/pair stop
```

### 查看状态

```bash
/pair status
```

### 请求建议

```bash
/pair suggest
```

## 快捷交互

| 说法 | 响应 |
|------|------|
| "帮我看看" | 分析当前代码 |
| "有问题" | 诊断问题 |
| "怎么写" | 提供实现建议 |
| "优化一下" | 优化建议 |
| "测试用例" | 生成测试 |
| "解释一下" | 解释代码 |

## 建议类型

### 📝 代码补全

智能代码补全，基于上下文：

```typescript
// 你写: function getUser
// 建议: function getUserById(id: string): Promise<User>
```

### 🔧 代码优化

发现可优化的代码：

```typescript
// 你写: if (user !== null && user !== undefined)
// 建议: if (user) 或使用可选链
```

### ⚠️ 错误检测

即时检测潜在错误：

```typescript
// 检测: user.name 可能为 undefined
// 建议: 使用 user?.name
```

### 🧪 测试建议

编写测试时提供用例建议：

```typescript
// 建议测试用例:
// - should return user when valid id
// - should throw error when not found
```

## 困难检测

### 检测信号

- 同一行修改 > 5 次
- 1 分钟内撤销 > 10 次
- 5 分钟无进展
- 2 分钟内搜索 > 5 次

### 响应方式

```text
⚠️ 检测到你可能遇到了困难:
   需要我帮忙看看吗? [Y/n]
```

### 适合场景

- ✅ 重构代码

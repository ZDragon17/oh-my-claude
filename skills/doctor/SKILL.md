# Doctor 诊断修复技能 v1.0

> 灵感来源：华佗 - 妙手回春，起死回生
> 核心理念：自动诊断安装问题，一键修复

## 概述

Doctor（诊断修复）是一种**自动化问题诊断和修复工具**，
专门用于检测和修复 oh-my-claude 的安装问题、配置错误和依赖缺失。

与手动排查的区别：
- **手动排查**：逐个检查文件和配置
- **Doctor**：自动化检测，一键修复

## 使用方式

### 命令格式

```bash
# 完整诊断（默认）
/zhenduan

# 英文命令
/doctor

# 简写
/diag
```

### 诊断模式

```bash
# 完整诊断（默认）
/zhenduan

# 快速诊断（只检测关键项）
/zhenduan --quick

# 指定检测项
/zhenduan --check=commands,agents

# 详细输出
/zhenduan --verbose
```

### 修复操作

```bash
# 诊断并自动修复
/zhenduan --fix

# 仅显示修复建议（不执行）
/zhenduan --dry-run

# 强制重新安装
/zhenduan --reinstall

# 清理并重装
/zhenduan --clean-install
```

## 自动修复能力

### 可自动修复

| 问题类型 | 修复方式 |
|----------|----------|
| 旧版文件残留 | 自动删除 |
| 配置文件格式错误 | 尝试修复或重新生成 |
| 权限问题 | 自动修复权限 |
| 缺失文件 | 从源重新复制 |
| 版本不一致 | 自动更新 |

### 需手动修复

| 问题类型 | 建议操作 |
|----------|----------|
| 环境依赖缺失 | 安装 Node.js/Claude Code |
| 网络问题 | 检查网络连接 |
| 严重配置损坏 | 建议重新安装 |
| 自定义配置冲突 | 手动合并配置 |

## 与其他命令的关系

### 与 /verify 的区别

| 特性 | /verify | /zhenduan |
|------|---------|-----------|
| 深度 | 快速验证 | 完整诊断 |
| 修复 | 不支持 | 支持自动修复 |
| 适用 | 安装后确认 | 问题排查 |

### 与 /diagnose 的区别

`/diagnose` 是 `/zhenduan` 的英文别名，功能相同。

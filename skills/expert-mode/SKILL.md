# 专家模式技能

为熟悉 oh-my-claude 的高级用户提供精简输出模式。

## 功能说明

专家模式启用后：
- ✂️ 跳过新手引导和教程提示
- 📉 减少解释性文字
- ⚡ 直接执行任务，减少确认
- 🎯 输出更加简洁精炼

## 使用方式

### 临时启用（单次会话）

```
/expert on
```

启用后显示：
```text
⚡ 专家模式已启用

• 跳过引导和教程提示
• 减少解释性输出
• 直接执行任务

💡 关闭: /expert off
```

### 临时关闭

```
/expert off
```

关闭后显示：
```text
📖 已切换到标准模式

• 恢复引导和提示
• 显示详细解释
```

### 查看当前状态

```
/expert status
```

输出：
```text
当前模式: ⚡ 专家模式
```
或
```text
当前模式: 📖 标准模式
```

## 模式对比

| 场景 | 标准模式 | 专家模式 |
|------|----------|----------|
| `/help` 无历史 | 显示新手引导 | 直接显示速查表 |
| Agent 完成任务 | 详细解释 + 建议 | 简洁结果 |
| 错误发生 | 详细错误翻译 + 多个恢复选项 | 错误摘要 + 首选建议 |
| `/yishan` 启动 | 完整愚公移山说明 | 直接创建TODO开始执行 |
| `/verify` | 完整验证报告 | 仅显示问题项 |

## 实现细节

### 状态存储

专家模式状态存储在会话上下文中：

```json
{
  "expertMode": true
}
```

或使用本地文件：

```bash
# 启用
echo "expert" > ~/.oh-my-claude/mode

# 关闭
rm ~/.oh-my-claude/mode
```

### 行为调整

当专家模式启用时，各命令应：

1. **跳过欢迎/引导信息**
   - 不显示 "👋 看起来你是新用户"
   - 不显示 "/tutorial" 提示

2. **精简输出格式**
   - 使用紧凑的表格而非详细说明
   - 省略 "💡 提示" 类辅助信息

3. **减少确认步骤**
   - 合理假设用户意图
   - 直接执行而非询问确认

4. **错误处理更直接**
   - 给出最可能的解决方案
   - 不列出所有可能选项

## 输出示例对比

### `/help` 命令

**标准模式：**
```text
👋 看起来你是新用户！

🚀 快速入门:
  /tutorial   → 5分钟交互式教程
  /do [任务]  → 直接开始，系统自动帮你

📚 深入了解:
  /agents     → 查看所有专家
  /recipes    → 查看场景指南

┌─────────────────────────────────────────────────────────────┐
│                 🏔️ oh-my-claude 快速参考                    │
├─────────────────────────────────────────────────────────────┤
...
```

**专家模式：**
```text
┌─────────────────────────────────────────────────────────────┐
│                 🏔️ 快速参考                                  │
├─────────────────────────────────────────────────────────────┤
│  /yishan 大任务  /zhuge 架构  /luban 实现  /bianque Bug诊断 │
│  /wukong 探索    /sunzi 性能  /mozi 安全   /baozheng 测试   │
└─────────────────────────────────────────────────────────────┘
```

### 错误恢复

**标准模式：**
```text
❌ 命令执行失败

🔍 错误分析:
   原因: 文件不存在
   位置: src/auth/login.ts
   
🔧 恢复选项:
   1. /retry     - 重试上次操作
   2. /skip      - 跳过此步骤
   3. /rollback  - 回滚到上个状态
   4. /bianque   - 深度诊断问题

💡 建议: 使用 /retry 重试，系统会自动调整策略
```

**专家模式：**
```text
❌ src/auth/login.ts 不存在

→ /retry 或创建文件后继续
```

# 统计分析技能 (Statistics & Analytics)

为 oh-my-claude 提供全面的使用统计和性能分析能力。

## 核心理念

> 没有度量，就没有改进。
> 数据驱动的洞察，帮助优化工作流程。

## 功能特性

### 1. Agent 性能分析

追踪每个 Agent 的使用情况：

| 指标 | 说明 | 计算方式 |
|------|------|----------|
| 调用次数 | Agent 被调用的总次数 | 累计统计 |
| 成功率 | 任务成功完成的比例 | 成功次数/总次数 |
| 平均耗时 | 每次调用的平均时间 | 总耗时/调用次数 |
| Token 消耗 | 估算的 Token 使用量 | 基于输入输出长度 |
| 趋势 | 使用频率的变化趋势 | 近期 vs 历史 |

### 2. Hook 执行统计

监控 Hook 系统的健康状态：

- 执行次数
- 平均响应时间
- 最慢响应时间
- 失败率

### 3. 会话统计

当前会话的实时数据：

- 会话时长
- 消息数量
- Agent 调用分布
- 任务完成进度

## 洞察生成规则

### 成功率分析

| 成功率 | 评价 | 建议 |
|--------|------|------|
| ≥ 95% | ⭐ 优秀 | 继续保持 |
| 85-94% | ✅ 良好 | 关注边界情况 |
| 75-84% | ⚠️ 需改进 | 任务描述更明确 |
| < 75% | ❌ 问题 | 检查使用方式 |

### Token 消耗分析

| Agent 类型 | 预期消耗 | 原因 |
|------------|----------|------|
| Explore | 低 (1-3K) | 主要是搜索和浏览 |
| Plan | 高 (10-20K) | 需要深度思考和规划 |
| debugger | 中 (3-8K) | 诊断和分析 |
| general-purpose | 中高 (5-15K) | 代码实现 |

### 趋势判断

```
近 7 天调用次数 vs 前 7 天:
  • 增长 > 20%: ↗️ 热门
  • 增长 > 50%: 🔥 爆发
  • 下降 > 20%: ↘️ 下降
  • 变化 < 20%: → 稳定
  • 首次使用: 🆕 新增
```

## 使用示例

```bash
# 查看 Agent 统计
/stats agents

# 查看综合概览
/stats

# 查看 Hook 性能
/stats hooks

# 查看当前会话
/stats session
```

## 隐私说明

- 所有统计数据存储在本地
- 不会上传到任何服务器
- 用户可随时清除统计数据

```bash
# 清除统计数据
rm -rf ~/.oh-my-claude/stats/
rm ~/.oh-my-claude/logs/hooks-perf.log
```

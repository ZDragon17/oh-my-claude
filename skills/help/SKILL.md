# 命令发现助手

当用户需要帮助或不知道使用哪个命令时，提供智能推荐和搜索功能。

## 触发方式

- `/help` - 显示快速参考
- `/help [关键词]` - 搜索相关命令
- `/commands` - 显示完整命令列表
- `/commands [分类]` - 按分类筛选

# 代码时间旅行技能 (Code Timeline)

查看文件的修改历史并进行 AI 分析。

## 核心理念

> 了解过去，指导未来。
> 代码演进，一目了然。

## 功能概述

### ⏰ 查看历史

查看文件或目录的修改历史：

```bash
/timeline src/auth/login.ts
/timeline src/auth/
```

### 🔍 版本详情

查看特定提交的详细信息：

```bash
/timeline show abc1234
```

### 🔀 版本比较

比较两个版本之间的差异：

```bash
/timeline compare abc1234 def5678
```

### 📊 模式分析

AI 分析修改模式和趋势：

```bash
/timeline analyze src/auth/
```

### ⏪ 回滚操作

安全地回滚到指定版本：

```bash
/timeline revert abc1234
```

## 时间线视图

### 提交历史

```text
📅 2026-01-23 14:30 [abc1234] @鲁班
   feat: 添加 JWT 刷新令牌逻辑
   ├─ 影响: 增加了 token 过期处理
   ├─ +45 行 / -12 行
   └─ 关联: #issue-456
```

### 提交类型图标

| 类型 | 图标 | 说明 |
|------|------|------|
| feat | ✨ | 新功能 |
| fix | 🐛 | Bug 修复 |
| refactor | ♻️ | 重构 |
| test | 🧪 | 测试 |
| docs | 📚 | 文档 |
| perf | ⚡ | 性能 |

## AI 分析

### 修改模式分析

分析文件的修改规律：

- **活跃度**: 提交频率、主要贡献者
- **类型分布**: feat/fix/refactor 比例
- **风险区域**: 频繁修改的高风险代码
- **建议**: 基于分析的改进建议

### 贡献者分析

分析各 Agent 的贡献：

- 提交数量和比例
- 主要贡献类型
- 代码质量评估

### 影响分析

分析变更的影响范围：

- 依赖关系图
- 风险评估
- 测试覆盖情况

## 风险等级

| 级别 | 图标 | 说明 |
|------|------|------|
| 低 | 🟢 | 小改动，影响范围小 |
| 中 | 🟡 | 涉及核心逻辑，需要测试 |
| 高 | 🔴 | 重大变更，需要审查 |

## 回滚安全

### 回滚前检查

1. 显示将撤销的变更
2. 分析影响范围
3. 检查依赖关系
4. 提示潜在风险

### 建议做法

- 先在分支上测试回滚
- 确认测试通过后再合并
- 保留回滚的提交记录

## Git 集成

依赖 Git 命令获取历史：

```bash
git log --follow -- <path>
git show <hash>
git diff <hash1> <hash2>
git revert <hash>
```

## 最佳实践

### 查看历史

- 使用 `/timeline` 了解文件演进
- 关注高频修改的文件
- 了解重大变更的背景

### 版本比较

- 比较前后版本理解变化
- 代码审查时使用
- 排查问题时追溯

### 分析模式

- 定期分析项目健康度
- 识别技术债务
- 优化开发流程


### 与 /debug 集成


# 交互式调试技能 (Interactive Debug)

智能诊断错误、分析堆栈、提供修复建议的调试助手。

## 核心理念

> 错误是学习的机会。
> 快速定位，精准修复。

## 诊断流程

```
┌─────────────────────────────────────────────────────────────┐
│  1. 收集错误信息                                            │
│     ├─ 终端输出                                            │
│     ├─ 错误日志                                            │
│     └─ 用户粘贴的错误信息                                   │
├─────────────────────────────────────────────────────────────┤
│  2. 识别错误类型                                            │
│     ├─ 语法错误                                            │
│     ├─ 类型错误                                            │
│     ├─ 运行时错误                                          │
│     └─ 网络/数据库错误                                      │
├─────────────────────────────────────────────────────────────┤
│  3. 定位问题源                                              │
│     ├─ 解析堆栈跟踪                                        │
│     ├─ 定位文件和行号                                      │
│     └─ 读取相关代码                                        │
├─────────────────────────────────────────────────────────────┤
│  4. 分析根因                                                │
│     ├─ 检查变量状态                                        │
│     ├─ 分析执行流程                                        │
│     └─ 识别常见模式                                        │
├─────────────────────────────────────────────────────────────┤
│  5. 生成修复建议                                            │
│     ├─ 多种修复方案                                        │
│     ├─ 代码示例                                            │
│     └─ 最佳实践建议                                        │
└─────────────────────────────────────────────────────────────┘
```

## 错误模式库

### JavaScript/TypeScript

| 错误类型 | 常见原因 | 快速修复 |
|----------|----------|----------|
| TypeError | 空值访问 | 可选链 `?.` |
| ReferenceError | 变量未定义 | 检查声明/导入 |
| SyntaxError | 语法错误 | 运行 linter |
| ModuleNotFound | 路径/依赖问题 | npm install |

### Python

| 错误类型 | 常见原因 | 快速修复 |
|----------|----------|----------|
| AttributeError | 空值/属性缺失 | getattr/hasattr |
| ImportError | 模块问题 | pip install |
| KeyError | 键不存在 | dict.get() |
| IndentationError | 缩进问题 | 修复缩进 |

### 数据库

| 错误类型 | 常见原因 | 快速修复 |
|----------|----------|----------|
| Connection | 服务未启动 | 启动数据库 |
| Query | SQL 错误 | 检查语法 |
| Timeout | 慢查询 | 优化索引 |

## 交互式命令

在交互式模式下可用：

| 命令 | 说明 |
|------|------|
| `error <msg>` | 诊断错误信息 |
| `trace` | 分析堆栈 |
| `watch <var>` | 建议变量监控点 |
| `breakpoint` | 建议断点位置 |
| `fix <n>` | 应用第 n 个修复方案 |
| `history` | 查看诊断历史 |
| `exit` | 退出调试模式 |

## 与扁鹊集成

`/debug` 内部调用 🩺 扁鹊 Agent：

```
/debug → 调用 Task(subagent_type="debugger")
```

扁鹊的诊断能力：
- 深度代码分析
- 执行流程追踪
- 边界情况检测
- 修复方案评估

## 知识库集成

诊断结果可保存到知识库：

```bash
# 保存解决方案
/error save "空值检查修复"

# 查询历史解决方案
/error search "undefined"
```

知识库路径: `~/.oh-my-claude/errors/`

## 使用场景

### 错误诊断

```bash
# 诊断粘贴的错误
/debug error "TypeError: Cannot read property 'map' of undefined"

# 诊断最近的错误
/debug
```

### 堆栈分析

```bash
# 分析堆栈跟踪
/debug trace
# 然后粘贴堆栈信息
```

### 文件诊断

```bash
# 诊断特定文件
/debug file src/components/UserList.tsx
```

### 交互式调试

```bash
# 进入交互式模式
/debug interactive
> error "TypeError..."
> fix 1
> exit
```

## 最佳实践

1. **提供完整信息** - 包含完整错误消息和堆栈
2. **描述复现步骤** - 说明如何触发错误
3. **尝试修复建议** - 按推荐顺序尝试
4. **保存解决方案** - 积累知识库

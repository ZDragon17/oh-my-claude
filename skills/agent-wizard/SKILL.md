# Agent 创建向导技能 (Agent Wizard)

交互式创建和管理自定义 Agent。

## 核心理念

> 每个项目都有独特需求。
> 定制你的专属 Agent。

## 功能概述

### 📋 列出 Agent

```bash
/agent list
```

### ✨ 创建 Agent

```bash
/agent create              # 交互式向导
/agent create huatuo       # 快速创建
/agent create --template debugger  # 使用模板
```

### ✏️ 编辑 Agent

```bash
/agent edit huatuo
```

### 🗑️ 删除 Agent

```bash
/agent delete huatuo
```

### 👀 查看详情

```bash
/agent show huatuo
```

### 📤 导出/导入

```bash
/agent export huatuo
/agent import huatuo.md
```

## 创建向导

### 6 步向导流程

1. **基本信息** - 名称、显示名、图标
2. **专长领域** - 选择或自定义专长
3. **人格设定** - 描述性格和风格
4. **工具权限** - 选择可用工具
5. **触发关键词** - 定义自动路由关键词
6. **确认创建** - 预览并确认

## 生成文件

### Agent 定义

`agents/<name>.md`:

```markdown
---
name: huatuo
displayName: 华佗
icon: 💊
description: 性能诊断专家
expertise: [性能优化, 代码清理]
tools: [Read, Grep, Glob, Bash]
keywords: [内存, 泄漏, 性能]
---

# 人格设定...
```

### 命令文件

`commands/<name>.md`:

```markdown
---
name: huatuo
description: 召唤华佗进行性能诊断
aliases: [/华佗]
---

# 命令内容...
```

## 最佳实践

### 命名规范

- 英文名：小写，无空格（如 `huatuo`）
- 中文名：历史人物或有意义的名称
- 图标：选择与专长相关的 emoji

### 人格设定

好的人格设定包括：
- 历史背景或角色原型
- 专业特点和工作风格
- 语气和表达方式

### 工具权限

- **诊断类**：建议只读权限
- **实现类**：需要写入权限
- **审查类**：建议只读权限

### 关键词

- 选择有代表性的词
- 包含中英文
- 避免太通用的词

# Research 研究编排技能 v1.0

> 灵感来源：玄奘取经 - 千里取经，穷尽真理
> 核心理念：并行探索，交叉验证，系统整合

## 概述

Research（研究编排）是一种**并行科学家编排**技能，
用于深度研究课题，多角度探索，交叉验证结论。

与普通搜索的区别：
- **普通搜索**：单一路径查找信息
- **Research**：多个科学家并行研究 + 结论整合 + 交叉验证

## 使用方式

### 命令格式

```bash
# 中文命令
/yanjiu 用户流失原因分析

# 英文命令
/research analyze user churn causes

# 简写
/rs 性能瓶颈分析
```

### 研究模式

```bash
# 标准研究（默认）
/yanjiu 系统性能分析

# 快速研究
/yanjiu --quick API 响应时间问题

# 深度研究（最彻底）
/yanjiu --thorough 用户行为建模

# 指定科学家数量
/yanjiu --scientists=5 竞品分析
```

## 研究类型

| 类型 | 说明 | 典型场景 |
|------|------|----------|
| 🔬 探索性研究 | 发现未知模式 | 新领域调研 |
| 📊 验证性研究 | 验证假设 | A/B 测试分析 |
| 📈 趋势分析 | 预测未来 | 增长预测 |
| ⚖️ 对比研究 | 比较方案 | 技术选型 |
| 🔍 根因分析 | 追溯原因 | 故障诊断 |

## 并行研究配置

### 科学家分配策略

```yaml
research_config:
  # 科学家数量
  scientists: 3-5
  
  # 分配策略
  assignment:
    - dimension: 数据维度
      scientist: scientist-1
      focus: 数据质量、统计分析
      
    - dimension: 业务维度
      scientist: scientist-2
      focus: 业务逻辑、用户行为
      
    - dimension: 技术维度
      scientist: scientist-3
      focus: 系统性能、架构影响
```

### 交叉验证

## 与其他技能的对比

| 特性 | Research | DeepSearch | 普通搜索 |
|------|----------|------------|----------|
| 目的 | 深度研究 | 全面查找 | 快速定位 |
| 方法 | 多科学家并行 | 多策略并行 | 单一搜索 |
| 输出 | 研究报告 | 搜索结果 | 匹配列表 |
| 验证 | 交叉验证 | 结果去重 | 无 |
| 适用 | 复杂课题 | 代码探索 | 简单查找 |

**选择建议**：
- 知道要找什么 → 普通搜索
- 需要全面了解 → DeepSearch
- 需要深度分析 → Research

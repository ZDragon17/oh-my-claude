# 团队协作技能 (Team Share)

分享 oh-my-claude 配置给团队成员，实现协作开发。

## 可分享内容

| 类型 | 路径 | 说明 |
|------|------|------|
| 配置 | .oh-my-claude/config.json | 项目配置 |
| 规则 | .oh-my-claude/rules/ | 编码规范 |
| Agent | .oh-my-claude/agents/ | 自定义 Agent |
| 片段 | ~/.oh-my-claude/snippets/ | 代码片段 |

## 使用场景

1. **新成员入职** - 快速获取团队配置
2. **项目交接** - 传递项目上下文
3. **最佳实践** - 分享优质 Agent 和片段

## 安全提示

- 不要分享包含敏感信息的配置
- 导入前检查内容
- 使用版本控制管理共享配置

# 新用户引导系统

当检测到新用户或用户明确需要引导时，提供友好的入门体验。

## 触发条件

1. 用户首次使用 oh-my-claude（无历史记录）
2. 用户输入 `/start` 或 `/开始`
3. 用户表达"不知道怎么用"、"从哪开始"等困惑

## 引导流程

### 第一步：欢迎界面

```text
👋 欢迎使用 oh-my-claude!

我是你的 AI 编程助手，集成了 20 个专业 Agent，
可以帮助你完成从需求分析到代码部署的完整流程。

🚀 快速开始 - 选择你要做的事:

  [1] 📝 实现一个新功能
  [2] 🐛 修复一个 Bug
  [3] 👀 审查代码质量
  [4] 🔍 探索了解代码库
  [5] ⏭️  跳过引导，自由探索

请输入数字 1-5 选择，或直接描述你的任务
```

### 第三步：确认理解

在用户选择场景后，确认用户意图并提供下一步操作：

```text

  1. 直接输入命令开始工作
  2. 输入 /help 查看更多命令
  3. 描述你的具体任务，我来推荐合适的命令

有任何问题随时问我！🎉
```

## 快捷入口

### /start 命令

用户可以随时输入 `/start` 重新进入引导流程。

### /quickstart 命令

提供极简版引导：

```text
🚀 oh-my-claude 极速入门

最常用的 6 个命令:

  /yishan   → 大任务，持续执行直到完成
  /bianque  → Bug 诊断，粘贴错误信息即可
  /weizheng → 代码审查
  /wukong   → 代码探索，快速定位
  /zhuge    → 架构设计
  /luban    → 代码实现

💡 记住: /help [关键词] 可以搜索任何功能
```

## 上下文感知

引导系统会根据当前项目上下文提供个性化建议：

- **检测到 package.json**: 推荐前端相关命令
- **检测到 pom.xml/build.gradle**: 推荐 Java 相关工作流
- **检测到 requirements.txt**: 推荐 Python 相关命令
- **检测到 .git**: 推荐 `/git` 相关命令
- **检测到测试文件**: 推荐 `/baozheng` 测试命令

## 引导完成标记

完成引导后，在用户目录创建标记文件：

```text
~/.oh-my-claude/onboarding-completed
```

下次启动时不再自动显示引导，但用户可以通过 `/start` 重新触发。

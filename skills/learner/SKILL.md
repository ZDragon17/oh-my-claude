# Learner 学徒技能 v1.0

> 灵感来源：中国传统师徒制度 - 学而时习之，温故而知新
> 核心理念：从经验中学习，将解决方案转化为可复用的知识

## 概述

Learner（学徒）技能用于从会话中**提取可复用的模式和经验**，
将成功的问题解决方案转化为可以在未来重复使用的技能模板。

## 核心功能

| 功能 | 说明 |
|------|------|
| 🎓 模式提取 | 从成功的会话中提取解决方案模式 |
| 📝 技能生成 | 自动生成可复用的技能文件 |
| 🔄 经验积累 | 建立团队/个人的知识库 |
| 🎯 模式匹配 | 在新问题中识别已知模式 |

## 使用方式

### 提取当前会话的经验

```bash
# 基本用法：从当前会话提取学习
/xuetu

# 指定提取内容
/learner extract "如何处理认证错误"

# 英文命令
/learner
```

### 查看已学习的模式

```bash
# 列出所有已学习的模式
/xuetu list

# 搜索特定模式
/xuetu search "认证"
```

### 应用已学习的模式

```bash
# 在新问题中应用已学习的模式
/xuetu apply "处理JWT过期"
```

## 自动学习触发

以下情况会建议运行学习提取：

| 触发条件 | 说明 |
|---------|------|
| 解决复杂问题后 | 成功解决耗时超过 10 分钟的问题 |
| 多次重复操作 | 检测到相似操作被执行多次 |
| 会话结束时 | 长会话结束时提示是否提取经验 |
| 用户请求 | 用户明确要求提取经验 |

## 智能匹配

当遇到新问题时，系统会自动匹配已学习的模式：

```
新问题: "JWT token 过期怎么处理？"
    ↓
搜索知识库
    ↓
找到匹配: auth-error-handling.md (相似度: 85%)
    ↓
建议: "发现类似问题的解决方案，是否应用？"
```

## 命令选项

```bash
# 提取并指定分类
/xuetu --category=patterns 提取认证相关经验

# 提取并添加标签
/xuetu --tags=auth,jwt,error 提取当前会话经验

# 从历史会话提取
/xuetu --session=ses_abc123

# 批量提取
/xuetu --batch 从最近10个会话提取经验

# 导出知识库
/xuetu export --format=json

# 导入知识库
/xuetu import knowledge.json

# 清理知识库
/xuetu prune --older-than=30d
```

## 与其他技能集成

### 自动应用已学习的模式

当扁鹊诊断时，自动搜索类似问题的解决方案：

```
用户: "这个错误怎么解决？TypeError: xxx"
    ↓
扁鹊诊断 + Learner 搜索
    ↓
输出: 诊断结果 + 已知类似问题的解决方案
```

### 团队知识共享

```bash
# 导出团队可共享的知识
/xuetu export --team

# 从团队知识库导入
/xuetu import --from-team
```

## 最佳实践

### 1. 及时提取

在解决问题后立即提取，趁记忆新鲜：

```bash
# 刚解决完一个复杂问题
/xuetu "JWT 刷新 Token 的完整流程"
```

### 2. 添加上下文

提供足够的上下文让模式更通用：

```bash
# 好：包含上下文
/xuetu --context="Next.js + Prisma 项目" 提取数据库查询优化经验

# 不好：缺少上下文
/xuetu 提取
```

### 3. 定期整理

定期整理和优化知识库：

```bash
# 每周整理
/xuetu prune --merge-similar
```

## 隐私说明

- 学习的模式仅保存在本地
- 不会上传到任何服务器
- 可以选择性地与团队共享
- 敏感信息（密码、密钥等）会被自动过滤

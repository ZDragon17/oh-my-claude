# 核心命令速查

oh-my-claude 有 55 个命令，但你**只需要记住 5 个**就能完成 90% 的工作。

---

## 🎯 5 个核心命令

### 1. `/do` - 万能入口

```bash
/do 你想做的任何事情
```

**等价于** `/yishan`，但更短。系统会自动：
- 分解任务为 TODO
- 选择合适的专家
- 持续执行直到完成

**示例**:
- `/do 实现用户登录功能`
- `/do 修复这个报错`
- `/do 优化首页加载速度`

---

### 2. `/help` - 找命令

```bash
/help [关键词]
```

不知道用什么命令？搜索一下：
- `/help 性能` → 推荐 `/sunzi`
- `/help 测试` → 推荐 `/baozheng`
- `/help bug` → 推荐 `/bianque`

---

### 3. `/status` - 看进度

```bash
/status
```

显示：
- 当前任务进度
- 活跃的 Agent
- 插件健康状态

---

### 4. `/retry` - 重试

```bash
/retry
```

上一个操作失败了？一键重试。

---

### 5. `/stuck` - 求助

```bash
/stuck
```

完全卡住不知道怎么办？这个命令会：
- 诊断你的问题
- 提供恢复选项
- 给出下一步建议

## 💡 使用技巧

### @语法召唤专家

在任何对话中使用 `@` 直接召唤：
- `@诸葛 帮我设计这个架构`
- `@扁鹊 这个报错怎么解决`
- `@悟空 找到认证相关的代码`

### 专家模式

熟练用户可以启用精简输出：
```bash
/expert on
```

### 查看别名

每个命令都有多个别名，使用你习惯的即可：
- `/do` = `/yishan` = `/yugong` = `/persist`
- `/zhuge` = `/longzhong` = `/strategy`
- 查看全部：[COMMAND_ALIASES.md](COMMAND_ALIASES.md)

# 核心命令速查

oh-my-claude 有 55+ 个命令，但你**只需要记住 5 个**就能完成 90% 的工作。

---

## 🎯 5 个核心命令

### 1. `/do` - 万能入口

```bash
/do 你想做的任何事情
```

**等价于** `/yishan`，但更短。系统会自动：
- 分解任务为 TODO
- 选择合适的专家
- 持续执行直到完成

**示例**:
- `/do 实现用户登录功能`
- `/do 修复这个报错`
- `/do 优化首页加载速度`

---

### 2. `/fix` - 修 Bug 🆕

```bash
/fix [错误描述]
```

遇到报错？直接用这个：
- `/fix TypeError: Cannot read property 'map' of undefined`
- `/fix 登录接口返回 500`
- `/fix 页面白屏了`

> 💡 等价于 `/bianque`，但更直观

---

### 3. `/check` - 审代码 🆕

```bash
/check [文件或代码]
```

需要代码审查？
- `/check src/services/user.ts`
- `/check staged` (审查暂存区)
- `/check 刚才写的代码`

> 💡 等价于 `/weizheng`，但更直观

---

### 4. `/ask` - 问专家 🆕

```bash
/ask [你的问题]
```

有问题要咨询？系统自动选专家：
- `/ask 架构怎么设计` → 诸葛
- `/ask 代码在哪里` → 悟空
- `/ask 为什么这么慢` → 孙子

---

### 5. `/help` - 找命令

```bash
/help [关键词]
```

不知道用什么命令？搜索一下：
- `/help 性能` → 推荐 `/sunzi`
- `/help 测试` → 推荐 `/baozheng`
- `/help bug` → 推荐 `/bianque`

## 💡 使用技巧

### @语法召唤专家

在任何对话中使用 `@` 直接召唤：
- `@诸葛 帮我设计这个架构`
- `@扁鹊 这个报错怎么解决`
- `@悟空 找到认证相关的代码`

### 专家模式

熟练用户可以启用精简输出：
```bash
/expert on
```

### 查看别名

每个命令都有多个别名，使用你习惯的即可：
- `/do` = `/yishan` = `/yugong` = `/persist`
- `/fix` = `/bianque` = `/debug`
- `/check` = `/weizheng` = `/review`
- `/zhuge` = `/longzhong` = `/strategy`
- 查看全部：[COMMAND_ALIASES.md](COMMAND_ALIASES.md)

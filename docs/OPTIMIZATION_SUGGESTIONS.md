## 二、可选优化建议 (非必须)

### 2.1 边缘场景 Hook

| Hook | 优先级 | 建议 |
|------|--------|------|
| non-interactive-env | 低 | 仅CI/CD环境需要，可选实现 |
| prometheus-md-only | 低 | 诸葛已具备规划能力 |

### 2.2 代码质量优化

1. **TypeScript 类型完善**
   - 部分配置类型使用 `any`，可替换为具体类型
   - 参考 oh-my-opencode 的 Zod schema

2. **测试覆盖率提升**
   - 当前覆盖率约 75%
   - 目标: 80%+

3. **文档国际化**
   - 部分技术文档仅有中文
   - 建议添加英文版本

### 2.3 用户体验优化

1. **安装后引导**
   - 首次安装后显示快速入门指南
   - 推荐常用命令

2. **错误提示优化**
   - 更友好的错误信息
   - 提供修复建议链接

3. **进度面板增强**
   - 支持更多展示模式
   - 添加预计完成时间

## 四、性能优化建议

### 4.1 启动速度

| 优化项 | 当前 | 目标 | 方法 |
|--------|------|------|------|
| Hook 加载 | 同步 | 懒加载 | 按需加载 Hook |
| MCP 连接 | 预连接 | 按需 | 首次使用时连接 |
| 配置读取 | 每次 | 缓存 | 配置热重载 |

### 4.2 内存优化

| 优化项 | 方法 |
|--------|------|
| Agent 提示词 | 按需加载，不常用 Agent 延迟加载 |
| 会话历史 | 实现滚动窗口，超出自动清理 |
| 日志 | 实现日志轮转 |

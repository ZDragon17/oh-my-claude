## 快速开始

### 1. 功能开发（最常用）

```bash
# 一步到位
/yishan 实现用户登录功能，包括表单验证和错误提示

# 或分步进行
/libai 分析登录功能需求        # 第一步：需求分析
/zhuge 设计登录模块架构        # 第二步：架构设计
/yishan 实现登录功能          # 第三步：编码实现
```

### 2. Bug 修复

```bash
# 粘贴错误信息即可
/bianque TypeError: Cannot read property 'name' of undefined

# 或者先定位再修复
/wukong 找到登录相关代码
/bianque 分析登录报错原因
```

### 3. 代码审查

```bash
# 审查单个文件
/weizheng 审查 src/services/user.ts

# 审查整个模块
/weizheng 审查 src/auth/ 目录的代码质量
```

## 团队协作示例

### 多人并行开发

```bash
# 开发者 A：实现后端 API
/yishan 实现用户管理 API

# 开发者 B：实现前端界面
/gukaizhi 实现用户管理页面

# 开发者 C：编写测试
/baozheng 为用户管理模块编写测试
```

### 紧急修复流程

```bash
# 1. 快速诊断
/bianque [生产环境错误日志]

# 2. 定位问题
/wukong 找到相关代码

# 3. 最小化修复
/luban 修复问题（不做额外修改）

# 4. 验证修复
/baozheng 运行相关测试
```

# 功能开发工作流

从需求分析到功能上线的完整开发流程。

## 适用场景

- 开发新功能
- 实现产品需求
- 添加新模块

## 详细步骤

### 步骤 1：需求分析

```bash
/libai 分析这个需求：实现用户注册功能，支持邮箱和手机号两种方式
```

李白会帮你：
- 提炼用户故事
- 识别功能边界
- 列出验收标准

### 步骤 2：架构设计（复杂功能）

```bash
/zhuge 设计用户注册模块的架构，需要考虑：
- 多种注册方式
- 验证码机制
- 用户数据存储
```

诸葛会提供：
- 技术方案对比
- 组件拆分建议
- 风险点识别

### 步骤 3：数据库设计（如需要）

```bash
/cangjie 设计用户表和验证码表的结构
```

仓颉会设计：
- 表结构
- 索引策略
- 数据关系

### 步骤 4：代码实现

```bash
# 推荐：愚公模式持续执行
/yishan 实现用户注册功能，包括：
- 注册表单组件
- 注册 API
- 验证码发送和校验
- 数据库操作
```

愚公会：
- 自动分解任务
- 持续执行直到完成
- 智能调用其他专家

### 步骤 5：测试验证

```bash
/baozheng 为用户注册模块编写测试用例，覆盖：
- 正常注册流程
- 验证码校验
- 异常情况处理
```

### 步骤 6：代码审查

```bash
/weizheng 审查 src/auth/register/ 目录的代码质量
```

### 步骤 7：文档完善

```bash
/simaqian 为用户注册模块编写 API 文档
```

## 快捷方式

### 一步到位（简单功能）

```bash
/yishan 实现用户注册功能
```

愚公会自动判断需要哪些步骤并执行。

### 分步控制（复杂功能）

如果需要更精细的控制，按上述步骤逐一执行。

---

## 注意事项

1. **复杂功能建议先设计**：避免返工
2. **及时测试**：边开发边测试，不要最后才测
3. **保持沟通**：不确定的需求及时确认
4. **代码审查**：上线前必须审查

---

## 示例：实现购物车功能

```bash
# 1. 需求分析
/libai 分析购物车功能需求，需要支持：添加商品、修改数量、删除商品、计算总价

# 2. 架构设计
/zhuge 设计购物车模块架构，考虑登录用户和游客两种场景

# 3. 数据库设计
/cangjie 设计购物车表和购物项表

# 4. 实现功能
/yishan 实现购物车完整功能

# 5. 测试
/baozheng 编写购物车功能的单元测试和集成测试

# 6. 审查
/weizheng 审查购物车模块代码
```

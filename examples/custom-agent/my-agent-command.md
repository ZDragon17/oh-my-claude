# /my-agent - Documentation Helper

Invoke this command to get help with code documentation.

## Usage

```
/my-agent [task description]
```

## Examples

```
/my-agent Add documentation to all functions in src/utils/
/my-agent Improve the README file
/my-agent Generate JSDoc for the UserService class
```

## What This Agent Does

1. Analyzes your codebase for documentation gaps
2. Adds or improves inline comments
3. Generates JSDoc/TSDoc documentation
4. Helps write README sections
5. Creates API documentation

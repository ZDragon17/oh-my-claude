# 极简执行命令 (Just Do It)

最简单的入口 - 直接说你要做什么，剩下的交给我。

---

## 核心理念

**用户不需要记任何命令。**

只需要：
```
/do [你想做的事情]
```

---

## 使用方式

### 基础用法
```
/do 给用户表添加手机号字段
/do 修复登录页面的样式问题
/do 写一个文件上传的API
/do 帮我review这段代码
/do 优化首页加载速度
```

### 等同于
```
/yishan [任务描述]
```

但更短、更直觉。

---

## 执行逻辑

当收到 `/do [任务]` 时：

1. **激活愚公移山模式** - 持续执行直到完成
2. **智能任务分析** - 理解任务类型
3. **自动分派Agent** - 根据任务调用合适的专家
4. **全程跟踪** - TODO管理 + 进度更新
5. **验证完成** - 确保任务真正完成

---

## 为什么要用 /do

| 传统方式 | /do 方式 |
|----------|----------|
| 先想用什么命令 | 直接说任务 |
| /zhuge 分析 → /luban 实现 | /do 实现功能 |
| 记住20个命令 | 记住1个 |
| 看文档选命令 | 开箱即用 |

## 进阶技巧

### 指定范围
```
/do 在 src/components/ 目录下添加一个按钮组件
```

### 指定约束
```
/do 用TypeScript重写这个模块，保持API不变
```

### 指定验证
```
/do 添加登录功能，确保测试通过
```

---

## 与其他命令的关系

- `/do` = `/yishan` 的简写
- 如果你知道具体要找谁，可以直接用 `/zhuge`、`/bianque` 等
- 不确定？就用 `/do`，系统会帮你找对的人

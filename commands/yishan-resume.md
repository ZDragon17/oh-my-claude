# 任务恢复

恢复之前暂停或中断的愚公移山任务。

## 职责

1. 读取检查点文件
2. 恢复 TODO 状态
3. 继续执行未完成的任务

## 恢复流程

### 1. 检查检查点

读取 `~/.oh-my-claude/yishan-checkpoint.json`，检查点格式如下：

```json
{
  "version": "1.0",
  "type": "pause|interrupt",
  "timestamp": "ISO时间",
  "task": { "description": "任务描述" },
  "todos": [...],
  "progress": {
    "completed": 4,
    "in_progress": "当前任务",
    "pending": 5,
    "total": 10,
    "percent": 40
  },
  "context_summary": "上下文摘要",
  "status": "paused|interrupted"
}
```

根据 `type` 字段判断是从暂停还是中断恢复，调整恢复提示信息

### 2. 如果找到检查点

```text
📂 检测到未完成任务

═══════════════════════════════════════════════════
📋 任务: [任务描述]
📊 进度: ████████████░░░░░░░░░░░░ 40% (4/10)
⏸️ 暂停: [X 小时/分钟] 前
═══════════════════════════════════════════════════

📝 任务概览:
   ✅ 已完成:
      • 探索代码结构
      • 设计实现方案
      • 实现用户注册 API
      • 添加表单验证

   🔄 待继续:
      • 实现用户登录功能 ← 从这里继续

   ⏳ 待完成:
      • 实现密码重置
      • 添加单元测试
      • 集成测试
      • 更新文档
      • 代码审查

═══════════════════════════════════════════════════

🔄 正在恢复任务...
```

然后：
1. 使用 TodoWrite 恢复 TODO 状态
2. 激活愚公移山模式
3. 从 `in_progress` 的任务继续执行

### 3. 如果没有检查点

```text
ℹ️ 没有找到可恢复的任务

💡 开始新任务:
   /yishan [任务描述]

📂 可能原因:
   • 之前的任务已完成
   • 检查点已过期（超过 7 天）
   • 检查点文件被删除
```

### 4. 如果检查点过期

```text
⚠️ 检查点已过期

找到的检查点创建于 [X] 天前，可能已不适用。

📋 任务: [任务描述]
📊 当时进度: 40% (4/10)

选择操作:
   [1] 仍然尝试恢复（可能需要重新理解上下文）
   [2] 放弃，开始新任务

输入 1 或 2 选择
```

## 恢复后的行为

恢复成功后，自动进入愚公移山模式：

```text
🏔️ 愚公移山模式已恢复！

📊 ████████████░░░░░░░░░░░░░░░░░░ 40% (4/10) 💪
🔄 继续: 实现用户登录功能

═══════════════════════════════════════════════════

正在继续执行...
```

## 响应要求

1. **无缝恢复** - 用户不需要重新描述任务
2. **状态同步** - TODO 列表与检查点保持一致
3. **上下文保持** - 尽量理解之前的工作进展
4. **透明反馈** - 清晰显示恢复了什么

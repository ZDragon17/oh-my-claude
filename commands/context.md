# 上下文管理器

监控和优化上下文使用，预防长会话崩溃。

## 核心理念

> 上下文如同内存，善用则畅通无阻，滥用则捉襟见肘。
> 智能管理上下文，让长任务持续稳定运行。

## 命令解析

根据 `$ARGUMENTS` 执行对应操作：

| 参数 | 操作 |
|------|------|
| (空) / `status` | 显示上下文状态 |
| `compact` | 压缩对话历史 |
| `clean` | 清理缓存和临时数据 |
| `export` | 导出重要信息 |

## 操作流程

### 1. /context 或 /context status

**显示上下文使用状态**

执行步骤：

1. **估算当前 Token 使用量**
   - 统计对话轮次
   - 估算代码上下文
   - 计算系统提示占用

2. **计算使用率**
   - 假设上下文窗口为 200K tokens
   - 计算当前占用百分比

3. **分析组成**
   - 对话历史占比
   - 代码上下文占比
   - 系统提示占比

4. **生成建议**
   - 根据使用率给出操作建议

**Token 估算方法**：
```
中文字符: 约 1.5 字符/token
英文字符: 约 4 字符/token
代码: 约 3 字符/token
```

**输出格式**：

### 2. /context compact

**压缩对话历史**

执行步骤：

1. **分析可压缩内容**
   - 早期探索对话
   - 已完成任务的细节
   - 重复的代码展示
   - 调试输出

2. **保留关键信息**
   - 当前 TODO 列表
   - 未完成任务上下文
   - 关键技术决策
   - 错误和解决方案

3. **生成压缩摘要**
   - 对话要点提取
   - 关键决策记录
   - 当前进度状态

4. **应用压缩**
   - 建议用户确认
   - 提供恢复方法

**输出格式**：
```text
🗜️ 上下文压缩分析
═══════════════════════════════════════════════════

📊 压缩前:
   使用率: 92% (~184,000 tokens)

📋 可压缩内容:
   ├── 早期探索对话 (轮次 1-15): ~30,000 tokens
   ├── 已完成任务细节: ~25,000 tokens
   ├── 重复代码展示: ~15,000 tokens
   └── 调试输出: ~10,000 tokens
   ────────────────────────────────────────
   总计可压缩: ~80,000 tokens

🔒 保留内容:
   ├── 当前 TODO 列表
   ├── 进行中任务上下文
   ├── 关键技术决策 (5项)
   └── 最近 10 轮对话

📊 压缩后预估:
   使用率: ~52% (~104,000 tokens)
   节省: ~80,000 tokens (40%)

═══════════════════════════════════════════════════

📝 压缩摘要（将保留）:

### 已完成工作
1. 完成代码探索，识别了认证模块结构
2. 设计了 JWT + Refresh Token 方案
3. 实现了 Token 生成和验证逻辑
4. 修复了 Token 过期处理的 Bug

### 关键决策
- 采用 JWT + Refresh Token 双令牌机制
- Access Token 有效期 15 分钟
- Refresh Token 有效期 7 天
- 使用 Redis 存储 Refresh Token

### 当前状态
- 进度: 40% (4/10 任务完成)
- 当前任务: 实现刷新 Token 机制
- 下一步: 实现登出功能

═══════════════════════════════════════════════════
💡 压缩建议已生成。请在下一轮对话中:
   1. 开始新话题时说 "继续之前的任务"
   2. 系统会自动加载压缩摘要
   3. 之前的详细对话将被释放
```

### 3. /context clean

**清理缓存和临时数据**

执行步骤：

1. **识别可清理内容**
   - 过期的上下文缓存
   - 临时文件引用
   - 未使用的代码快照

2. **执行清理**
   - 清理 `~/.oh-my-claude/context/` 缓存
   - 移除过期数据

**输出格式**：
```text
🧹 上下文清理
═══════════════════════════════════════════════════

🔍 扫描结果:
   ├── 过期缓存文件: 5 个
   ├── 临时上下文: 3 个
   └── 旧压缩记录: 2 个

🗑️ 已清理:
   释放空间: ~2.3 MB
   清理文件: 10 个

📊 清理后状态:
   缓存占用: 1.2 MB → 0.8 MB

═══════════════════════════════════════════════════
✅ 清理完成
```

### 4. /context export

**导出重要信息**

执行步骤：

1. **收集关键信息**
   - 当前 TODO 状态
   - 技术决策记录
   - 进度摘要

2. **生成导出文件**
   - 写入 `.claude/context-export.md`

**输出格式**：
```text
📤 上下文导出
═══════════════════════════════════════════════════

📁 已导出到: .claude/context-export.md

📋 导出内容:
   ├── TODO 列表 (10 项)
   ├── 技术决策 (5 项)
   ├── 进度摘要
   └── 关键代码引用 (3 个)

═══════════════════════════════════════════════════
💡 可以在新会话中使用此文件恢复上下文
💡 命令: 请阅读 .claude/context-export.md 继续工作
```

## 使用率等级

| 使用率 | 状态 | 图标 | 建议 |
|--------|------|------|------|
| 0-50% | 充裕 | 🟢 | 可自由工作 |
| 50-70% | 正常 | 🟢 | 关注变化 |
| 70-85% | 注意 | ⚠️ | 建议压缩 |
| 85-95% | 警告 | 🟠 | 尽快压缩 |
| 95%+ | 紧急 | 🚨 | 立即处理 |

## 进度条生成规则

```
使用率 N%，总长度 30 字符

填充字符: █
空白字符: ░

填充数 = floor(N / 100 * 30)
空白数 = 30 - 填充数
```

## 执行规则

1. **快速响应** - 状态查询应立即返回
2. **准确估算** - Token 估算基于合理的字符比例
3. **友好显示** - 使用进度条和图标增强可读性
4. **主动预警** - 高使用率时自动提示
5. **保留关键** - 压缩时保护重要上下文

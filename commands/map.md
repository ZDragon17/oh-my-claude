## 场景指引（`/map [场景]`）

当用户提供场景关键词时，显示针对性指引：

### `/map 错误恢复` 或 `/map error`

```text
┌──────────────────────────────────────────────────────────┐
│              ⚠️ 错误恢复命令流程                          │

│                                                          │
│  遇到错误后的决策树：                                     │
│                                                          │
│  错误发生 ─┬→ 想重试？ ─────→ /retry     智能重试        │
│            │                                             │
│            ├→ 想跳过？ ─────→ /skip      安全跳过        │
│            │                                             │
│            ├→ 想回滚？ ─────→ /rollback  恢复状态        │
│            │                                             │
│            ├→ 想诊断？ ─────→ /bianque   深度分析        │
│            │                                             │
│            └→ 完全卡住？ ───→ /stuck     恢复中心        │
│                                                          │
│  💡 快速修复: /quickfix [错误信息]                       │
│                                                          │
└──────────────────────────────────────────────────────────┘
```

# /metis - 召唤 Metis 计划顾问

Metis 是规划三角的第一环，专注于在正式规划开始前进行深度需求分析。

## 使用方式

```bash
# 分析一个需求
/metis 分析这个需求：实现用户登录功能

# 复杂任务预分析
/metis 我们要重构整个认证模块，包括 OAuth、JWT 和 Session 管理

# 检查歧义
/metis 这个需求有什么不清楚的地方？"优化首页性能"
```

## Metis 会做什么

1. **识别隐藏意图** - 发现用户没有明说但期望的功能
2. **检测歧义** - 找出可能导致误解的模糊点
3. **预判失败点** - 识别 AI 容易犯错的地方
4. **提供建议** - 给出需要澄清的问题和收集的信息

## 规划三角工作流

```
Metis (预分析) → 诸葛 (规划) → 刘伯温 (审查)
```

推荐的完整流程：

```bash
# 1. 先让 Metis 分析需求
/metis 分析需求：重构用户认证系统

# 2. 根据 Metis 的分析，让诸葛制定计划
/zhuge 基于 Metis 的分析，制定详细执行计划

# 3. 让刘伯温审查计划
/liubowen 审查这个执行计划的可行性
```

## 输出示例

```markdown
## Metis 需求分析报告

### 隐藏意图识别
| 隐藏意图 | 推断依据 | 置信度 |
|----------|----------|--------|
| 需要保持向后兼容 | 现有系统在运行 | 高 |
| 需要支持移动端 | 提到了"现代化" | 中 |

### 歧义点清单
| 歧义 | 可能解释 | 建议澄清方式 |
|------|----------|--------------|
| "用户" | 最终用户还是管理员？ | 直接询问 |

### AI 失败风险
| 风险 | 概率 | 缓解建议 |
|------|------|----------|
| 忽略现有集成 | 高 | 先调研现有系统 |

### 需要澄清的问题
1. 是否需要支持第三方登录？
2. 现有用户数据如何迁移？
```

## 与其他命令配合

| 场景 | 推荐流程 |
|------|----------|
| 大型功能开发 | `/metis` → `/zhuge` → `/liubowen` → `/yishan` |
| 重构任务 | `/metis` → `/zhuge` → `/yishan` |
| 快速任务 | 直接 `/yishan`（跳过分析） |

## 相关命令

- `/zhuge` - 诸葛战略顾问（规划阶段）
- `/liubowen` - 刘伯温计划审查（审查阶段）
- `/yishan` - 愚公移山（执行阶段）

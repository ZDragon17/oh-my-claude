## 协作流程 (增强版)

### 阶段一：智能任务分析

愚公使用 planner-sisyphus 算法进行深度任务分析：

```text
用户任务 → 复杂度评估 → 依赖建模 → Agent 匹配 → 并行规划 → 风险评估
```

**智能决策**：
- **任务复杂度**：1-10分制自动评分
- **依赖关系**：自动识别任务间的依赖链
- **Agent 匹配**：基于专长和可用性选择最佳组合
- **并行度分析**：识别可并行执行的任务组

### 阶段二：并行协作执行

支持多 Agent 同时工作，实时状态同步：

```text

   │
   ├─► [并行组A] @wukong + @cangjie (代码探索 + 数据库分析)
   │      ├─► 实时进度同步
   │      └─► 中间结果共享
   │
   ├─► [串行链B] @zhuge → @luban (架构设计 → 代码实现)
   │      ├─► 设计输出直接传递给实现
   │      └─► 自动依赖检查
   │
   ├─► [质量门C] @bianque + @weizheng (测试 + 代码审查)
   │      ├─► 并行质量检查
   │      └─► 问题自动分配修复
   │
   └─► [监控组D] @zhangheng (实时状态监控)
          ├─► 性能指标收集
          └─► 异常预警
```

## 调用语法 (增强版)

### 基础调用

在协作过程中，使用 `@agent_name` 召唤专家：

```markdown
@wukong 探索所有与用户认证相关的代码
@zhuge 设计用户模块的架构方案
@luban 实现 UserService 的 getProfile 方法
@bianque 诊断这个 TypeError 的根因
```

### 高级协作语法

支持复杂的协作模式：

```markdown
# 并行任务组

# 依赖链

# 条件执行
@bianque ? 如果测试失败，请诊断问题

# 循环协作
@luban → @bianque → @luban 实现-测试-修复循环

# 资源分配

```

## 协作原则 (增强版)

- **智能分工**：基于专长和任务特征自动分配专家
- **并行优化**：最大化利用并行执行机会
- **状态透明**：实时同步所有 Agent 的工作状态
- **依赖管理**：自动处理任务间的依赖关系
- **断点保护**：支持中断恢复和上下文续传
- **质量把关**：多层次的质量检查和问题修复
- **持续改进**：基于协作历史优化未来分配策略

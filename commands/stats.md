# 统计分析命令

显示 oh-my-claude 的使用统计和性能分析数据。

## 使用方法

```bash
/stats              # 显示概览
/stats agents       # Agent 使用统计
/stats hooks        # Hook 执行统计
/stats session      # 当前会话统计
/stats history      # 历史趋势
```

## 参数说明

用户输入: `$ARGUMENTS`

根据参数选择统计类型：
- 无参数或 `overview`: 显示综合概览
- `agents`: Agent 调用次数、成功率、耗时、Token 消耗
- `hooks`: Hook 执行统计
- `session`: 当前会话统计
- `history`: 历史趋势分析

## 数据来源

1. **Hook 性能日志**: `~/.oh-my-claude/logs/hooks-perf.log`
2. **会话历史**: `~/.oh-my-claude/sessions/`
3. **Agent 调用记录**: 从 Task 工具的输出中提取

## 执行步骤

### 步骤 1: 读取性能日志

```bash
# 检查日志文件是否存在
if [ -f "$HOME/.oh-my-claude/logs/hooks-perf.log" ]; then
    tail -100 "$HOME/.oh-my-claude/logs/hooks-perf.log"
fi
```

### 步骤 2: 统计 Agent 调用

从日志中提取 Agent 调用数据，计算：
- 调用次数
- 成功/失败次数
- 平均执行时间
- Token 消耗估算

### 步骤 3: 生成报告

按指定格式输出统计结果。

# 神行自动驾驶模式命令

> 🚀 从想法到代码，全程自动，无需干预

以《水浒传》神行太保戴宗为灵感，启动完全自主的 Autopilot 模式。

## 命令格式

```bash
# 中文命令
/shenxing 构建一个 REST API 管理任务

# 英文命令
/autopilot build a REST API for managing tasks

# 简写
/auto 实现用户登录功能
```

## 自然语言触发

```bash
# 以下表达会自动激活 Autopilot 模式
帮我构建一个博客系统
我想要一个待办事项应用
build me a todo app
I want a REST API
```

## 配置选项

```bash
# 快速模式：跳过测试和审查
/shenxing --fast 实现一个工具函数

# 严格模式：完整测试和安全审查
/shenxing --strict 实现支付模块

# 指定技术栈
/shenxing --tech=fastapi 构建 REST API

# 干燥运行：只生成计划不执行
/shenxing --dry-run 构建博客系统

# 组合模式
/shenxing --ultra 构建完整电商系统  # 超级自动驾驶
/shenxing --eco 实现简单 CRUD       # 节俭自动驾驶
```

## 执行流程

1. **需求分析** (李白) - 解析意图，提取需求
2. **架构设计** (诸葛) - 选择技术栈，设计架构
3. **代码实现** (鲁班 × N) - 并行创建模块
4. **质量保证** (包拯 + 墨子) - 测试 + 安全检查
5. **最终验证** (魏征) - 代码审查，输出报告

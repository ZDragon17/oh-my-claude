# 🤖 Agent 管理

你正在使用 **Agent 管理** 功能，创建、管理和配置自定义 Agent。

---

## 命令解析

根据用户输入 `$ARGUMENTS` 执行相应操作：

### 子命令分发

| 命令 | 说明 |
|------|------|
| `/agent list` | 列出所有可用 Agent |
| `/agent create` | 交互式创建新 Agent |
| `/agent create <name>` | 快速创建指定名称的 Agent |
| `/agent edit <name>` | 编辑现有 Agent |
| `/agent delete <name>` | 删除 Agent |
| `/agent show <name>` | 查看 Agent 详情 |
| `/agent export <name>` | 导出 Agent |
| `/agent import <file>` | 导入 Agent |

### 望 - 观察代码结构

- 了解性能表现
- 收集错误日志
- 获取用户反馈

- 发生频率

- 性能剖析

1. 紧急处理 - 快速缓解症状
2. 根治方案 - 解决根本问题

## 模板系统

### 预设模板

```bash
# 使用模板快速创建
/agent create --template debugger
/agent create --template optimizer
/agent create --template reviewer
```

### 可用模板

| 模板 | 说明 | 预设专长 |
|------|------|----------|
| debugger | 调试专家 | 调试诊断、错误分析 |
| optimizer | 优化专家 | 性能优化、代码清理 |
| reviewer | 审查专家 | 代码审查、安全审计 |
| documenter | 文档专家 | 文档编写、注释生成 |
| tester | 测试专家 | 测试编写、覆盖分析 |

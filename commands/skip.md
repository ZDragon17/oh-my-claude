# 跳过当前步骤

安全跳过当前失败或卡住的步骤，继续执行后续任务。

## 使用方式

```bash
/skip                     # 跳过当前步骤
/skip --reason "依赖缺失"  # 跳过并记录原因
```

## 执行流程

### 步骤 1: 确认当前步骤

读取当前 TODO 列表，找到 `in_progress` 状态的任务：

```text
⏭️ 准备跳过
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 当前任务: [任务描述]
📊 进度: [X]% ([completed]/[total])

⚠️ 跳过此步骤后，相关功能可能不完整。

确认跳过？
   • 输入 "确认" 或 "y" 跳过
   • 输入其他内容取消
```

### 步骤 2: 检查依赖关系

分析后续任务是否依赖当前任务：

如果有强依赖：

```text
⚠️ 依赖警告
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

以下任务依赖当前步骤:
   • [依赖任务 1]
   • [依赖任务 2]

💡 建议:
   [1] 先修复当前问题: /bianque
   [2] 跳过所有相关任务
   [3] 仍然只跳过当前任务（可能导致后续失败）

请选择操作。
```

### 步骤 3: 执行跳过

更新 TODO 状态，将当前任务标记为特殊状态：

**必须使用 TodoWrite**：
1. 将当前 `in_progress` 任务的内容修改为 `[已跳过] 原任务内容`
2. 将其状态改为 `completed`（视为"处理过"）
3. 将下一个 `pending` 任务改为 `in_progress`

### 步骤 4: 显示确认

```text
⏭️ 已跳过
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 跳过的任务: [任务描述]
📝 原因: [用户提供的原因，或"用户选择跳过"]

📊 更新后进度: ████████████░░░░░░░░░░░░ [X]% ([completed]/[total])
🔄 下一个任务: [下一个任务描述]

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

💡 提示: 跳过的任务已标记，可以稍后回来处理。
   查看跳过的任务: /status
```

然后**自动继续执行下一个任务**。

## 特殊场景

### 无活跃任务时

```text
ℹ️ 当前没有进行中的任务

如果你想开始新任务:
   • /yishan [任务描述] - 启动持续执行模式
   • 直接描述你想做什么
```

### 已是最后一个任务

```text
ℹ️ 这是最后一个任务
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📋 当前任务: [任务描述]

跳过后任务将结束。是否确认？
   [1] 确认跳过并结束
   [2] 取消，继续尝试当前任务
   [3] /bianque 诊断问题
```

### 跳过后显示摘要（任务结束时）

在整个任务完成时，显示跳过的步骤：

```text
📋 任务完成摘要
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 完成: 7 项
⏭️ 跳过: 1 项
   • [已跳过] 实现密码重置功能 - 原因: 依赖第三方服务

💡 建议: 稍后处理跳过的任务，确保功能完整。
```

## 与愚公移山模式集成

在 yishan 模式下，跳过后自动继续：

```text
📊 ████████████░░░░░░░░░░░░░░░░░░ 40% (4/10) ⏭️
⏭️ 已跳过: 实现密码重置
🔄 继续: 添加单元测试

正在执行下一步...
```

## 响应要求

1. **确认跳过** - 跳过前需要用户确认（除非在 yishan 模式下连续失败）
2. **记录原因** - 记录跳过的原因便于后续追踪
3. **检查依赖** - 警告可能受影响的后续任务
4. **自动继续** - 跳过后自动开始下一个任务

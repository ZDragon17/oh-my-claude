# 交互式教程 (Interactive Tutorial)

通过"边做边学"的方式快速掌握 oh-my-claude。专为新用户设计的引导系统。

---

## 设计理念

1. **渐进式学习** - 从简单到复杂，循序渐进
2. **动手实践** - 每个步骤都有实际操作
3. **即时反馈** - 完成后立即看到效果
4. **场景驱动** - 基于真实使用场景

---

## 使用方式

```
/tutorial [主题]
```

无参数显示教程目录。

---

### 教程 3：Bug 诊断

```text
📖 教程：Bug 诊断

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

遇到 Bug 时，使用扁鹊诊断:

🩺 扁鹊的诊断流程:
  1. 望 - 观察错误信息
  2. 闻 - 分析上下文
  3. 问 - 追问关键信息
  4. 切 - 定位根因

🎯 练习:
   假设你遇到这个错误:
   
   TypeError: Cannot read property 'name' of undefined
   
   试试输入:
   /bianque TypeError: Cannot read property 'name' of undefined
   
   观察扁鹊如何诊断这个问题。

💡 技巧:
  - 粘贴完整的错误信息效果更好
  - 可以附带相关代码片段
  - 描述问题出现的场景
```

### 教程 4：愚公移山进阶

```text
📖 教程：愚公移山进阶

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
掌握持续执行的高级技巧
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

愚公移山模式的核心是"不完成不罢休"。

🔄 工作流程:
  分析任务 → 创建TODO → 逐个完成 → 验证质量 → 清理代码

⚙️ 控制命令:
  /progress        查看进度
  /pause           安全暂停
  /yishan-resume   恢复任务
  /cancel-yishan   取消任务

🎯 练习:
   尝试一个稍复杂的任务:
   
   /yishan 实现一个简单的计数器组件，包含增加、减少、重置功能

   在执行过程中:
   - 输入 "显示进度" 查看当前状态
   - 观察 Agent 是如何协作的
   - 注意测试和代码清理环节

💡 高级技巧:
  - 任务描述越清晰，结果越好
  - 可以指定技术栈和约束
  - 遇到问题会自动调用扁鹊诊断
```

## 互动反馈

教程支持以下互动指令:

| 输入 | 作用 |
|------|------|
| `下一步` / `next` | 进入下一步 |
| `上一步` / `back` | 返回上一步 |
| `跳过` / `skip` | 跳过当前教程 |
| `重来` / `restart` | 重新开始当前教程 |
| `退出` / `exit` | 退出教程 |
| `帮助` / `help` | 显示教程帮助 |

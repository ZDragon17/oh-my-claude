# 工作流模板系统 (Workflow Templates)

**预设工作流程，一键执行复杂任务链。**

---

## 核心理念

**将常见的多步骤工作流程模板化，减少重复操作。**

- 🎯 **预设工作流** - 内置常见开发场景的最佳实践流程
- 🔧 **自定义保存** - 将当前会话保存为可复用的工作流
- 🔄 **自动编排** - 按依赖关系自动调度多个 Agent

---

## 使用方式

```
/workflow [子命令] [参数]
```

### 子命令列表

| 子命令 | 功能 | 示例 |
|--------|------|------|
| `list` | 列出所有可用工作流 | `/workflow list` |
| `run <name>` | 执行指定工作流 | `/workflow run feature` |
| `show <name>` | 查看工作流详情 | `/workflow show bugfix` |
| `save <name>` | 保存当前会话为工作流 | `/workflow save my-flow` |
| `edit <name>` | 编辑工作流 | `/workflow edit feature` |
| `delete <name>` | 删除工作流 | `/workflow delete my-flow` |
| `share <name>` | 分享工作流 | `/workflow share feature` |

## 自定义工作流

### 保存当前会话为工作流

```
/workflow save my-custom-flow
```

系统会：
1. 分析当前会话中调用的 Agent 顺序
2. 提取每个阶段的任务描述
3. 保存为可复用的工作流模板

### 控制命令

| 命令 | 功能 |
|------|------|
| `/workflow pause` | 暂停当前工作流 |
| `/workflow resume` | 恢复暂停的工作流 |
| `/workflow skip` | 跳过当前阶段 |
| `/workflow cancel` | 取消工作流执行 |
| `/workflow status` | 查看执行状态 |

## 工作流配置

### 配置文件位置

```
~/.oh-my-claude/workflows/
├── feature.json       # 内置工作流
├── bugfix.json
├── refactor.json
├── security.json
├── review.json
├── deploy.json
└── custom/            # 用户自定义工作流
    ├── my-flow.json
    └── team-flow.json
```

### 工作流 JSON 格式

```json
{
  "name": "feature",
  "description": "新功能开发完整流程",
  "version": "1.0.0",
  "stages": [
    {
      "name": "需求分析",
      "agent": "libai",
      "prompt_template": "分析以下需求，提取用户故事：{task}",
      "optional": false,
      "timeout": 300
    },
    {
      "name": "架构设计",
      "agent": "zhuge",
      "prompt_template": "基于需求分析结果，设计技术方案",
      "optional": true,
      "condition": "task.complexity > 'simple'"
    }
  ],
  "options": {
    "allow_skip": true,
    "auto_retry": true,
    "generate_report": true
  }
}
```

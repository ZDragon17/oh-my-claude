# 卡住恢复 (Stuck Recovery)

当你完全卡住、不知道怎么继续时，使用这个命令获得系统化的帮助。

---

## 使用方式

```
/stuck [问题描述]
```

无参数时进入交互式诊断流程。

---

## 核心理念

**你永远不应该在问题面前感到无助。**

这个命令会：
1. 诊断你当前的状态
2. 分析可能的卡住原因
3. 提供具体的恢复步骤
4. 推荐合适的专家帮助

---

## 交互式诊断

当用户输入 `/stuck` 无参数时，显示：

```text
🆘 卡住恢复中心

别担心，我来帮你！先告诉我你的情况:

  [1] 🔴 任务执行失败，不知道怎么修
  [2] 🟠 愚公模式一直循环，停不下来
  [3] 🟡 不知道接下来该做什么
  [4] 🔵 代码改坏了，想恢复
  [5] 🟣 完全不知道发生了什么

输入数字 1-5，或直接描述你的问题
```

---

## 诊断响应

### 情况 1：任务执行失败

```text
🔴 任务执行失败

📋 诊断清单:

1️⃣ 查看错误信息
   → 输入 /quickfix 获取修复建议
   → 或粘贴错误信息给 /bianque

2️⃣ 重试操作
   → /retry 智能重试上次失败的操作

3️⃣ 跳过当前步骤
   → /skip 跳过后继续下一步

4️⃣ 寻求深度诊断
   → /bianque [描述问题] 让扁鹊诊断

💡 常见原因:
  • 依赖未安装 → npm install / pip install
  • 权限问题 → 检查文件权限
  • 网络问题 → 检查网络连接
  • 类型错误 → 检查类型定义

推荐下一步: /bianque 诊断
```

### 情况 2：愚公循环停不下来

```text
🟠 愚公模式循环

📋 停止方法:

1️⃣ 自然语言停止（活跃会话中）
   → 输入: "停止" 或 "取消任务" 或 "stop"

2️⃣ 命令停止（新会话中）
   → /cancel-yishan

3️⃣ 强制中断
   → 按 Ctrl+C 中断当前操作

📊 检查状态:
   → 输入 "显示进度" 查看当前状态
   → 检查是否有卡住的 TODO

💡 常见原因:
  • 测试一直失败 → 检查测试用例
  • 依赖问题 → 检查环境配置
  • 无限循环逻辑 → 检查退出条件

推荐下一步: 先 "停止"，再 /bianque 诊断
```

### 情况 3：不知道下一步

```text
🟡 不知道接下来做什么

📋 快速定位:

1️⃣ 查看当前状态
   → /progress 查看任务进度
   → /status 快速状态

2️⃣ 获取建议
   → /suggest [描述你的目标]
   → /what [你想做什么]

3️⃣ 查看场景指南
   → /recipes 查看常见工作流
   → /help [关键词] 搜索命令

4️⃣ 查看专家列表
   → /agents 查看所有专家及其专长

💡 如果是全新任务:
   直接用 /do [任务描述]
   系统会自动规划和执行

推荐下一步: /do [描述你的目标]
```

### 情况 4：代码改坏了

```text
🔵 代码需要恢复

📋 恢复选项:

1️⃣ 回滚最近更改
   → /rollback 撤销最近的修改

2️⃣ Git 恢复（如果用了 Git）
   → git status 查看更改
   → git checkout -- <file> 恢复单个文件
   → git stash 暂存所有更改

3️⃣ 检查更改范围
   → git diff 查看具体改了什么
   → 找到问题代码手动恢复

4️⃣ 从头开始
   → /yishan 重新实现（自动创建新版本）

⚠️ 注意: /rollback 只能恢复 oh-my-claude 创建的更改
   对于 Git 仓库，建议使用 Git 命令更精确

推荐下一步: git status 检查状态
```

### 情况 5：完全不知道发生了什么

```text
🟣 完全迷失

📋 系统化恢复:

1️⃣ 深呼吸，不要慌 🧘

2️⃣ 查看最近的操作
   → /status 查看当前状态
   → 回想最后做了什么

3️⃣ 检查项目状态
   → git status （如果用 Git）
   → 看看有什么文件被修改

4️⃣ 寻求帮助
   → 描述你的情况，我来分析
   → /bianque [描述问题]

5️⃣ 最后手段：重新开始
   → git stash 保存当前更改
   → 重新描述你的任务

💡 提示:
   把你遇到的情况详细描述出来，
   包括：你想做什么、做了什么、发生了什么。
   我会帮你分析并找到解决方案。

推荐下一步: 描述你的情况
```

## 紧急恢复清单

快速参考：

| 问题 | 快速解决 |
|------|----------|
| 任务失败 | `/retry` 或 `/bianque` |
| 循环不停 | 输入 "停止" 或 `/cancel-yishan` |
| 不知下一步 | `/do [目标]` 或 `/suggest` |
| 代码改坏 | `/rollback` 或 `git checkout` |
| 完全迷失 | `/status` 然后描述问题 |

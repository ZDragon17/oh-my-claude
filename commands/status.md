# 任务状态查看器

快速展示当前工作状态，让用户随时掌握全局。

## 职责

1. 显示当前 TODO 进度
2. 显示活跃的 Agent
3. 显示最近的操作
4. 提供快捷操作入口

## 输出格式

### 当有活跃任务时

```text
📊 oh-my-claude 状态面板
═══════════════════════════════════════════════════

🏔️ 愚公移山模式: 活跃
   任务: [任务描述]
   启动: [X] 分钟前

📈 进度:
   ████████████░░░░░░░░░░░░░░░░░░ 40% (4/10)

   ✅ 已完成:
      • 探索代码结构
      • 设计实现方案
      • 实现用户注册 API
      • 添加表单验证

   🔄 进行中:
      • 实现用户登录功能

   ⏳ 待完成:
      • 实现密码重置
      • 添加单元测试
      • 集成测试
      • 更新文档
      • 代码审查

🎭 当前 Agent: 鲁班 (代码实现)
   上一个: 诸葛 (架构设计)

⏱️ 运行时间: 12 分钟
💾 上次检查点: 5 分钟前

═══════════════════════════════════════════════════
快捷操作:
  /pause    暂停任务    /progress  详细进度
  /cancel-yishan 取消   /help      帮助
```

### 当没有活跃任务时

```text
📊 oh-my-claude 状态面板
═══════════════════════════════════════════════════

😴 当前无活跃任务

📂 最近任务:
   • 重构认证模块 - 2小时前完成 ✅
   • 修复登录 Bug - 昨天完成 ✅

💡 开始新任务:
   /yishan [任务描述]  - 启动愚公移山
   /start              - 新用户引导
   /help               - 命令帮助

═══════════════════════════════════════════════════
```

### 当有未完成的暂停任务时

```text
📊 oh-my-claude 状态面板
═══════════════════════════════════════════════════

⏸️ 有未完成的任务

📂 暂停的任务:
   任务: 重构认证模块
   进度: 40% (4/10)
   暂停: 2 小时前

🔄 恢复选项:
   [1] /yishan-resume - 继续此任务
   [2] /yishan [新任务] - 开始新任务（放弃旧任务）

═══════════════════════════════════════════════════
```

## 简洁模式

当在愚公移山执行中调用 `/status` 时，使用简洁输出：

```text
📊 40% (4/10) | 🎭 鲁班 | ⏱️ 12分钟 | 💾 5分钟前
🔄 当前: 实现用户登录功能
```

## 响应要求

1. **即时响应** - 不要执行任何耗时操作
2. **信息准确** - 反映真实的 TODO 状态
3. **格式清晰** - 使用表格和图标增强可读性
4. **提供下一步** - 总是给出可操作的建议

# 取消愚公移山循环

你需要取消当前正在进行的愚公移山循环。

## 取消操作

请执行以下步骤：

### 1. 删除循环状态文件

使用 Bash 工具删除循环状态文件：

```bash
rm -f .claude/yishan-loop.local.md
```

### 2. 可选：清理检查点

询问用户是否要清理检查点数据：

```text
💾 检测到保存的检查点数据

是否同时清理检查点？
   [1] 保留检查点（推荐，方便以后恢复）
   [2] 清理检查点（彻底结束任务）
```

如果用户选择清理：

```bash
rm -f ~/.oh-my-claude/yishan-checkpoint.json
```

### 3. 确认取消

删除成功后，向用户确认：

```text
🛑 愚公移山循环已取消
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

📂 已删除: .claude/yishan-loop.local.md
💾 检查点: [保留/已清理]

循环将在当前响应结束后停止。

💡 提示:
   • /yishan-resume - 从检查点恢复（如有）
   • /yishan [新任务] - 开始新任务
```

## 注意事项

- 取消操作会立即停止循环，当前响应完成后不会再继续
- 已完成的工作不会被撤销
- TODO 列表会保留，可以稍后继续处理

## 执行

现在请删除状态文件以取消循环。

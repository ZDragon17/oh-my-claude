# /progress - 可视化进度面板

显示当前任务的执行进度、Agent 状态和工作统计。

## 使用方法

```bash
/progress           # 显示完整进度面板
/progress brief     # 简洁模式
/progress stats     # 仅显示统计信息
```

```

├─ ✅ 已完成: 4
├─ 🔄 进行中: 1
├─ ⏳ 待处理: 5
└─ 📈 完成率: 40%
```

## 进度条样式

根据完成百分比显示不同颜色提示：

- `0-25%`：刚开始，加油！🚀
- `26-50%`：稳步推进中 💪
- `51-75%`：过半了，胜利在望 🎯
- `76-99%`：冲刺阶段！🏃
- `100%`：大功告成！🎉

## 与 TodoWrite 集成

此命令读取 TodoWrite 工具维护的任务列表，自动生成可视化进度。

当用户请求查看进度时：
1. 获取当前所有 TODO 项
2. 计算完成百分比
3. 按状态分组显示
4. 添加视觉增强元素

## 响应语言

- 中文输入 → 中文面板

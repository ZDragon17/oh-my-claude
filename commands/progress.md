# /progress - 可视化进度面板

显示当前任务的执行进度、Agent 状态和工作统计。

## 使用方法

```bash
/progress           # 显示完整进度面板
/progress brief     # 简洁模式
/progress stats     # 仅显示统计信息
/progress kanban    # 看板模式（卡片视图）
/progress board     # 同 kanban
```

## 参数说明

用户输入: `$ARGUMENTS`

根据参数选择模式：
- 无参数或 `full`: 完整进度面板
- `brief`: 简洁单行模式
- `stats`: 统计信息
- `kanban` 或 `board`: 看板卡片视图

## 进度条样式

根据完成百分比显示不同颜色提示：

- `0-25%`：刚开始，加油！🚀
- `26-50%`：稳步推进中 💪
- `51-75%`：过半了，胜利在望 🎯
- `76-99%`：冲刺阶段！🏃
- `100%`：大功告成！🎉

## 与 TodoWrite 集成

此命令读取 TodoWrite 工具维护的任务列表，自动生成可视化进度。

当用户请求查看进度时：
1. 获取当前所有 TODO 项
2. 计算完成百分比
3. 按状态分组显示
4. 添加视觉增强元素

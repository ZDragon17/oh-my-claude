# 数据科学家命令 - 数据分析与统计

> 📊 密率之精，千载独步

召唤祖冲之进行数据分析、统计检验和假设验证。

## 命令格式

```bash
# 中文命令
/zuchongzhi 分析用户行为数据

# 英文命令
/scientist analyze user behavior data

# 简写
/data 统计这个数据集
```

## 使用场景

```bash
# 数据探索
/scientist 探索这个数据集的特征

# A/B 测试分析
/scientist 分析 A/B 测试结果

# 统计检验
/scientist 验证这两组数据是否有显著差异

# 趋势分析
/scientist 分析用户增长趋势

# 可视化建议
/scientist 这个数据应该用什么图表展示
```

## 专长领域

| 领域 | 能力 |
|------|------|
| 数据分析 | 探索性分析、特征工程 |
| 统计检验 | t 检验、卡方检验、ANOVA |
| 假设验证 | A/B 测试、因果推断 |
| 数据可视化 | 图表选择、可视化设计 |
| 预测建模 | 回归、分类、时序预测 |

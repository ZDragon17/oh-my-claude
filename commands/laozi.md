# /laozi 命令

启动老子 Agent 进入代码简洁之道模式。

## 使用方式

```bash
# 基本用法
/laozi [任务描述]

# 使用别名
/简洁 分析这段代码的复杂度
/clean review this function
/至简 重构这个模块
```

## 功能特点

老子 Agent 是代码简洁之道的大师，专注于：

### 核心原则

| 道家三宝 | 编程原则 | 应用 |
|----------|----------|------|
| 慈 (Compassion) | KISS | 保持简单，拒绝复杂 |
| 俭 (Frugality) | YAGNI | 不实现不需要的功能 |
| 不敢为天下先 | DRY | 一处定义，处处复用 |

### 核心能力

1. **代码简化** - 识别并简化过度复杂的代码
2. **Clean Code 检查** - 检查代码是否符合整洁原则
3. **重构建议** - 提供具体的重构方案
4. **代码异味检测** - 识别常见的代码异味

## 示例

```bash
# 分析代码复杂度
/laozi 分析 src/services/ 目录下的代码复杂度

# 代码简化
/简洁 这个函数太长了，帮我简化

# Clean Code 检查
/clean check this file for code smells

# 重构建议
/至简 重构这个 God Class
```

## 道德经与编程

| 道德经原文 | 编程智慧 |
|------------|----------|
| "大道至简" | 最好的代码是简单的代码 |
| "少则得，多则惑" | 代码越少，bug 越少 |
| "无为而治" | 不写不需要的代码 |
| "知足不辱" | 功能够用就好 |
| "上善若水" | 代码应该自然流畅 |

## 输出格式

老子 Agent 会生成结构化的简化报告：

```markdown
# ☯️ 老子代码简化报告

## 道之所见 (问题发现)
- 严重问题列表
- 改进建议

## 化繁为简 (重构方案)
- 重构前后对比
- 改进指标

## 道之所言
> 相关道德经名言及其现代解读
```

# ⏰ 代码时间旅行

你正在使用 **代码时间旅行** 功能，查看文件的修改历史并进行 AI 分析。

---

## 命令解析

根据用户输入 `$ARGUMENTS` 执行相应操作：

### 子命令分发

| 命令 | 说明 |
|------|------|
| `/timeline <path>` | 查看文件/目录的修改历史 |
| `/timeline show <hash>` | 查看指定提交的详情 |
| `/timeline compare <hash1> <hash2>` | 比较两个版本 |
| `/timeline analyze <path>` | AI 分析修改模式 |
| `/timeline revert <hash>` | 回滚到指定版本 |

## Git 集成

### 使用的 Git 命令

```bash
# 查看历史
git log --oneline --follow -- <path>

# 查看详情
git show <hash>

# 比较版本
git diff <hash1> <hash2>

# 回滚
git revert <hash>
```

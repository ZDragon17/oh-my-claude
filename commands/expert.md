# 专家模式开关

切换专家模式，控制输出详细程度。

## 使用方式

```text
/expert [on|off|status]
```

## 执行逻辑

### `/expert on` - 启用专家模式

1. 创建模式标记文件：
```bash
mkdir -p ~/.oh-my-claude && echo "expert" > ~/.oh-my-claude/mode
```

2. 显示确认：
```text
⚡ 专家模式已启用

效果:
• 跳过新手引导
• 精简输出格式
• 减少确认步骤

关闭: /expert off
```

### `/expert off` - 关闭专家模式

1. 删除模式标记文件：
```bash
rm -f ~/.oh-my-claude/mode
```

2. 显示确认：
```text
📖 已切换到标准模式

效果:
• 显示完整引导
• 详细解释说明
• 更多操作提示
```

### `/expert status` - 查看当前状态

1. 检查模式文件：
```bash
cat ~/.oh-my-claude/mode 2>/dev/null
```

2. 根据结果显示：

文件存在且内容为 "expert"：
```text
当前模式: ⚡ 专家模式
```

文件不存在或内容不匹配：
```text
当前模式: 📖 标准模式
```

### `/expert` 无参数 - 切换模式

检查当前状态并切换到相反模式：
- 如果当前是专家模式 → 切换到标准模式
- 如果当前是标准模式 → 切换到专家模式

## 适用场景

### 推荐使用专家模式

- ✅ 熟悉 oh-my-claude 所有命令
- ✅ 不需要引导和解释
- ✅ 追求效率，减少阅读时间
- ✅ 屏幕空间有限

### 推荐使用标准模式

- ✅ 新用户或偶尔使用
- ✅ 需要详细的操作指引
- ✅ 遇到复杂问题需要多选项
- ✅ 正在学习命令用法

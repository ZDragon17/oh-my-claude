# 代码审查命令 (Code Check)

**直观的代码审查入口** - `/weizheng` 的英文别名，用于代码审查和质量检查。

---

## 核心功能

```
/check [文件路径或代码描述]
```

自动调用魏征 (WeiZheng) 进行代码审查。

---

## 使用示例

```bash
# 审查指定文件
/check src/services/user.ts

# 审查暂存区代码
/check staged

# 审查最近的修改
/check 刚才写的代码

# 审查 PR
/check pr #123
```

---

## 审查维度

魏征会从三个维度进行审查：

| 维度 | 检查内容 |
|------|----------|
| 🪞 **铜镜** | 代码规范（格式、命名、风格） |
| 👤 **人镜** | 逻辑审查（设计、架构、模式） |
| 📚 **史镜** | 最佳实践（历史经验、常见陷阱） |

---

## 审查分级

| 级别 | 标识 | 含义 |
|------|------|------|
| 🔴 | [MUST] | 必须修复，阻塞合并 |
| 🟡 | [SHOULD] | 强烈建议修改 |
| 🟢 | [COULD] | 可选改进 |
| 💬 | [FYI] | 仅供参考 |

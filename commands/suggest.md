# 智能命令推荐 (Smart Suggest)

根据用户描述的任务，智能推荐最合适的命令。

---

## 使用方式

```
/suggest [你想做什么]
```

---

## 推荐格式

当用户输入 `/suggest [描述]` 时，按以下格式回复：

```
🎯 根据你的需求，我推荐：

**主推命令**: /[命令名] - [一句话说明]

**原因**: [为什么推荐这个命令]

**使用示例**:
/[命令名] [具体任务描述]

**备选命令**:
- /[备选1] - 如果需要[某功能]
- /[备选2] - 如果需要[某功能]
```

---

## 示例

### 输入
```
/suggest 我想给登录页面加一个验证码功能
```

### 输出
```
🎯 根据你的需求，我推荐：

**主推命令**: /yishan 给登录页面添加验证码功能

**原因**: 这是一个涉及前端UI和后端逻辑的完整功能，愚公模式会持续执行直到完成。

**使用示例**:
/yishan 给登录页面添加图形验证码功能，包括前端展示、后端生成和验证逻辑

**备选命令**:
- /gukaizhi - 如果只需要设计验证码的UI样式
- /luban - 如果只需要实现后端验证逻辑
```

---

## 快捷方式

如果不确定，直接输入：
```
/suggest 帮我选命令
```

系统会展示完整的命令分类供你选择。

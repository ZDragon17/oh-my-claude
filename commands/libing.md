# /libing 命令

召唤 **李冰 DevOps 水利家** 处理 CI/CD 和基础设施任务。

## 使用方式

```bash
# 基础用法
/libing <DevOps 需求>

# 使用别名
/dujiangyan <需求>
/devops <需求>
/cicd <需求>
/运维 <需求>
```

## 示例

```bash
# CI/CD 流水线
/libing 搭建 GitHub Actions CI/CD 流水线

# 容器化部署
/devops 将这个 Node.js 应用容器化

# 基础设施
/cicd 用 Terraform 配置 AWS ECS 集群

# 自动化运维
/运维 编写自动化部署脚本
```

## 李冰的专长

1. **CI/CD 流水线** - GitHub Actions、GitLab CI、Jenkins
2. **容器化部署** - Docker、Kubernetes、Docker Compose
3. **基础设施即代码** - Terraform、Pulumi、CloudFormation
4. **自动化运维** - 部署脚本、健康检查、回滚机制

# 智能意图识别 (What)

根据用户描述的目标，智能分析意图并推荐最合适的命令和 Agent。

---

## 使用方式

```
/what [你想达成的目标]
```

---

## 回复格式

当用户输入 `/what [描述]` 时，按以下格式回复：

```
🎯 意图分析

我理解你想要: [一句话总结用户意图]

📌 推荐方案

**首选**: /[命令] [Agent名] - [专长]
→ 示例: /[命令] [针对用户需求的具体任务描述]

**备选**:
- /[命令2] - 如果 [特定场景]
- /[命令3] - 如果 [特定场景]

💡 快速开始

直接复制执行:
```
/[命令] [用户的任务]
```
```

---

## 示例

### 输入
```
/what 我想给系统加一个导出Excel的功能
```

### 输出
```
🎯 意图分析

我理解你想要: 为系统添加数据导出为Excel文件的功能

📌 推荐方案

**首选**: /yishan 愚公 - 完整功能实现
→ 这是一个完整的功能需求，愚公会持续执行直到功能完成

**备选**:
- /luban - 如果只需要实现导出逻辑的核心代码
- /zhuge - 如果需要先讨论技术方案（用哪个库等）

💡 快速开始

直接复制执行:
```
/yishan 实现Excel导出功能，支持选择要导出的数据列，生成.xlsx格式文件
```
```

## 快捷方式

如果不确定怎么描述，可以用：
```
/what 帮我选命令
```

系统会展示完整的分类指南供你选择。

## 模糊表达识别

当用户表达不够清晰时，主动询问：

### 模糊表达示例

| 用户说... | 系统回应 |
|-----------|----------|
| "帮帮我" | "请告诉我具体想做什么，例如：修bug、写功能、审查代码..." |
| "这个有问题" | "请描述具体问题：是报错了？性能差？还是代码质量问题？" |
| "优化一下" | "请明确优化方向：性能优化？代码简化？UI优化？" |

## 复杂任务拆解

当识别到复杂任务时，主动拆解并推荐流程：

### 输入
```
/what 我想从零开始做一个用户管理系统
```

### 输出
```
🎯 意图分析

我理解你想要: 构建完整的用户管理系统

📌 这是一个复杂任务，建议分步进行:

**推荐流程**:
1️⃣ /libai 分析需求 → 明确功能范围
2️⃣ /zhuge 设计架构 → 技术方案设计  
3️⃣ /cangjie 设计数据库 → 表结构设计
4️⃣ /yishan 实现功能 → 持续执行直到完成

**或者一步到位**:
/yishan 实现用户管理系统，包括注册、登录、权限管理

💡 建议: 复杂系统推荐使用分步流程，便于把控质量
```

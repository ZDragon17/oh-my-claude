# 智能咨询命令 (Ask Expert)

**直观的咨询入口** - 根据问题类型自动路由到最合适的专家。

---

## 核心功能

```
/ask [你的问题]
```

系统会自动识别问题类型，调用最合适的专家：
- 架构问题 → 诸葛 (ZhuGe)
- 代码探索 → 悟空 (WuKong)  
- 性能问题 → 孙子 (SunZi)
- 安全问题 → 墨子 (MoZi)
- 通用问题 → 愚公 (YuGong)

---

## 使用示例

```bash
# 架构咨询
/ask 微服务架构怎么设计比较好

# 代码探索
/ask 认证模块的代码在哪里

# 性能问题
/ask 为什么这个接口这么慢

# 通用问题
/ask 如何实现用户登录功能
```

---

## 智能路由规则

| 关键词 | 调用专家 |
|--------|----------|
| 架构、设计、策略、微服务 | 🎯 诸葛 |
| 找、定位、在哪、搜索代码 | 🔍 悟空 |
| 性能、慢、优化、缓存 | ⚔️ 孙子 |
| 安全、漏洞、注入、xss | 🛡️ 墨子 |
| 测试、单测、覆盖率 | ⚖️ 包拯 |
| 数据库、sql、表设计 | 📊 仓颉 |
| 其他问题 | 🏔️ 愚公 |

---

## 与其他命令的关系

| 命令 | 区别 |
|------|------|
| `/ask` | 智能路由，根据问题选专家 |
| `/do` | 执行任务，持续工作直到完成 |
| `/fix` | 专门修 Bug |
| `/check` | 专门审查代码 |

---

> 💡 **使用建议**:
> - 有具体问题想咨询 → `/ask`
> - 有任务要执行 → `/do`
> - 有 Bug 要修 → `/fix`

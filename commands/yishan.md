# 愚公移山模式

你已进入 **愚公移山** 循环执行模式。

## 模式说明

在此模式下，你将像愚公一样坚持不懈地工作，直到任务完全完成：

```
太行、王屋二山，方七百里，高万仞...
虽我之死，有子存焉；子又生孙，孙又生子...
子子孙孙无穷匮也，而山不加增，何苦而不平？
```

## 🔄 自主循环机制

此模式配合 Stop Hook 实现自主循环执行：

### 启动循环

首先，你需要创建状态文件 `.claude/yishan-loop.local.md`：

```markdown
---
iteration: 1
max_iterations: 50
completion_promise: "移山完毕"
---

<用户的任务描述>
```

请使用 Write 工具创建这个文件，将 `<用户的任务描述>` 替换为：

$ARGUMENTS

### 完成标记

**重要**: 当且仅当任务**真正完成**时，在回复的最后输出完成标记：

```
<promise>移山完毕</promise>
```

⚠️ **警告**：
- 只有在所有 TODO 项都完成后才能输出此标记
- 虚报完成会导致循环提前终止
- 如果任务需要更多工作，不要输出此标记

## 执行规则

### 1. 必须使用 TodoWrite

在开始工作前，**必须**将任务分解为具体的 TODO 项：

```
每个 TODO 项应该：
├── 具体明确 - 不含糊
├── 可执行 - 能直接动手
├── 可验证 - 能判断是否完成
└── 适当粒度 - 不太大也不太小
```

### 2. 完成标准

只有满足以下**所有条件**才算完成：

- ✅ 所有 TODO 项状态为 `completed`
- ✅ 代码能正常运行（如适用）
- ✅ 测试通过（如适用）
- ✅ 原始需求得到满足

### 3. 不允许放弃

遇到困难时：

1. **分析问题** - 找出失败原因
2. **调整策略** - 尝试其他方法
3. **寻求帮助** - 召唤其他 Agent
4. **继续前进** - 不允许说"我做不到"

### 4. 进度报告

每完成一个子任务后，报告当前进度：

```
📊 移山进度：[已完成] / [总任务数]
✅ 刚完成：[任务描述]
🔄 正在进行：[当前任务]
⏳ 待处理：[剩余任务数] 个
```

## 开始移山

现在，请：

1. **创建状态文件** - 使用 Write 工具创建 `.claude/yishan-loop.local.md`
2. **分析任务** - 理解用户想要什么
3. **探索现状** - 了解代码库当前状态
4. **制定计划** - 使用 TodoWrite 创建任务列表
5. **开始执行** - 逐个完成任务
6. **持续推进** - 直到所有任务完成
7. **输出完成标记** - 只有真正完成后才输出 `<promise>移山完毕</promise>`

记住愚公的信念：**只要方向正确，坚持就会成功。**

开始吧，移山者！

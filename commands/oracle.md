# /oracle - 召唤神谕咨询师

召唤 Oracle (神谕) 进行高智商咨询。Oracle 是只读咨询师，专注于深度分析和建议，不直接修改代码。

## 使用场景

| 场景 | 示例 |
|------|------|
| 架构决策 | `/oracle 我们应该用微服务还是单体架构？` |
| 代码审查 | `/oracle 审查一下这段认证代码的安全性` |
| 深度调试 | `/oracle 这个内存泄漏问题怎么定位？` |
| 方案评估 | `/oracle 评估一下用 Redis 做缓存的方案` |

## 特点

- **只读分析** - 不会修改任何代码
- **深度思考** - 使用高级推理模型
- **证据支持** - 每个结论都有代码证据
- **多角度** - 从正确性、安全性、性能、可维护性等多角度分析

## 示例

```bash
# 架构咨询
/oracle 我们的支付系统应该如何设计？需要考虑：
- 高并发
- 数据一致性
- 审计追踪

# 代码审查
/oracle 请审查 src/auth/ 目录下的认证实现

# 调试分析
/oracle 用户登录后 token 有时会失效，帮我分析可能的原因
```

## 输出格式

Oracle 会提供结构化的分析报告，包括：
- 问题分析
- 方案对比（如适用）
- 风险评估
- 具体建议

## 注意

Oracle 是咨询师，不是执行者。获得建议后，需要由其他 Agent（如愚公、鲁班）来执行具体的代码修改。

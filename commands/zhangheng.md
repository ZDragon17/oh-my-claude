# /zhangheng 命令

召唤 **张衡监控观测家** 处理系统监控和可观测性任务。

## 使用方式

```bash
# 基础用法
/zhangheng <监控需求>

# 使用别名
/didongyi <需求>
/monitor <需求>
/observe <需求>
/监控 <需求>
```

## 示例

```bash
# 设计监控方案
/zhangheng 为这个微服务设计监控方案

# 日志分析
/monitor 分析这些日志找出错误原因

# 告警配置
/监控 配置 CPU 使用率超过 80% 的告警

# 链路追踪
/observe 追踪这个请求在各服务间的调用链
```

## 张衡的专长

1. **系统监控** - CPU、内存、磁盘、网络
2. **日志分析** - 结构化日志、日志聚合
3. **链路追踪** - 分布式追踪、请求链路
4. **告警配置** - 告警规则、通知策略

## 触发关键词

在消息中包含以下关键词会自动提示使用张衡：

- 监控、日志、告警、追踪
- monitor、logging、alert、trace
- metrics、prometheus、grafana
- 可观测、observability

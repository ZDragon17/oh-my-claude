# QA 测试员命令 - 交互式测试

> 🔍 元芳，你怎么看？

召唤狄仁杰进行交互式 CLI 测试和手动测试执行。

## 命令格式

```bash
# 中文命令
/direnjie 测试这个命令行工具

# 英文命令
/qa-tester test this CLI tool

# 简写
/qa 测试登录功能
```

## 使用场景

```bash
# CLI 测试
/qa-tester 测试 myapp 命令行工具

# API 测试
/qa-tester 测试用户注册 API

# 功能测试
/qa-tester 手动测试购物车功能

# 探索性测试
/qa-tester 探索这个新功能可能的问题

# 测试用例设计
/qa-tester 为登录功能设计测试用例
```

## 专长领域

| 领域 | 能力 |
|------|------|
| CLI 测试 | 命令行工具交互测试 |
| API 测试 | REST/GraphQL 接口测试 |
| 手动测试 | 功能验证、回归测试 |
| 探索性测试 | 发现未知问题 |
| 测试设计 | 测试用例编写 |

## 与包拯的区别

| 特性 | 包拯 (`/baozheng`) | 狄仁杰 (`/qa-tester`) |
|------|-------------------|---------------------|
| 类型 | 自动化测试 | 手动/交互测试 |
| 重点 | 测试代码编写 | 实际执行测试 |
| 适用 | TDD、单元测试 | 功能验证、探索测试 |

## 命令别名

- `/direnjie` - 狄仁杰（中文）
- `/qa-tester` - QA Tester（英文）
- `/qa` - QA（简写）
- `/manual-test` - 手动测试

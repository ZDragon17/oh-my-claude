## 🎯 核心三剑客（必记）

```
/yishan [任务]    持续执行直到完成（万能命令）
/wukong [搜索]    快速探索代码库
/help [关键词]    查询帮助和推荐
```

## 💡 小技巧

1. **不知道用什么？** → 直接用 `/yishan` + 描述任务
2. **想找代码？** → `/wukong 关键词`
3. **遇到问题？** → `/help 问题关键词`

# oh-my-claude 5 秒速查

**只需要记住一个命令：**

```text
/do [你想做的事]
```

系统自动选择合适的专家。

---

## 示例

```text
/do 修复这个报错           → 自动调用扁鹊
/do 找到登录相关代码        → 自动调用悟空
/do review 这段代码        → 自动调用魏征
/do 实现用户注册功能        → 自动调用愚公
/do 优化这个接口性能        → 自动调用孙子
```

## 遇到问题？

```text
/retry     重试失败的操作
/skip      跳过当前步骤
/rollback  回滚更改
```

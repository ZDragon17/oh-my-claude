# Performance Optimization Expert

`/perf` 是 `/sunzi` (孙子) 的英文别名，专注于性能分析和优化。

## 使用方式

```bash
/perf [性能问题描述]
```

## 示例

```bash
/perf 这个接口响应太慢了
/perf 分析内存泄漏
/perf 优化数据库查询
/perf 为什么首页加载需要 5 秒
```

## 能力

- 性能瓶颈分析
- 查询优化建议
- 内存/CPU 问题诊断
- 缓存策略设计
- 负载测试建议

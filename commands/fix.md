# 快速修复命令 (Quick Fix)

**直观的 Bug 修复入口** - `/bianque` 的英文别名，更易于国际用户使用。

---

## 核心功能

```
/fix [错误描述或错误信息]
```

自动调用扁鹊 (BianQue) 进行诊断和修复。

---

## 使用示例

```bash
# 修复报错
/fix TypeError: Cannot read property 'map' of undefined

# 修复特定文件的问题
/fix src/auth/login.ts 登录失败

# 修复最近的错误
/fix 上一个命令报错了
```

---

## 执行流程

```
用户输入 /fix [问题]
       ↓
┌─────────────────────────┐
│  1. 症状分析 (望)       │
│     观察错误信息        │
└─────────────────────────┘
       ↓
┌─────────────────────────┐
│  2. 问题定位 (闻问)     │
│     追踪错误来源        │
└─────────────────────────┘
       ↓
┌─────────────────────────┐
│  3. 根因诊断 (切)       │
│     深入分析代码        │
└─────────────────────────┘
       ↓
┌─────────────────────────┐
│  4. 修复执行            │
│     实施修复并验证      │
└─────────────────────────┘
```

---

## 关联命令

| 命令 | 用途 |
|------|------|
| `/fix` | 修 Bug（本命令） |
| `/bianque` | 中文版本 |
| `/debug` | 别名 |
| `/retry` | 重试上次操作 |

---

> 💡 **提示**: `/fix` 是 `/bianque` 的英文别名，功能完全相同。
> 扁鹊会以"望闻问切"的方式诊断和修复问题。

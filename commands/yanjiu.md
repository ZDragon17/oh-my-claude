# /yanjiu - 研究编排命令

## 概述

`/yanjiu` 启动并行研究编排模式，多个科学家 Agent 同时研究不同维度，
最终整合结论形成完整的研究报告。

## 使用方法

```bash
# 基本用法
/yanjiu <研究课题>

# 快速研究
/yanjiu --quick <课题>

# 深度研究
/yanjiu --thorough <课题>

# 指定科学家数量
/yanjiu --scientists=5 <课题>
```

## 别名

- `/research` - 英文命令
- `/rs` - 简写
- `/xuanwu` - 玄奘取经（传统文化别名）

## 示例

```bash
# 用户行为分析
/yanjiu 分析用户在结账流程中的流失原因

# 性能研究
/research API 响应时间异常的根因分析

# 技术选型
/rs --scientists=4 Next.js vs Remix vs SvelteKit 选型分析

# 深度研究
/yanjiu --thorough 系统可扩展性分析与优化方案
```

## 工作流程

```
1. 课题分解 → 识别研究维度
2. 分配科学家 → 每人负责一个维度
3. 并行研究 → 同时进行数据分析
4. 结论收集 → 汇总各方发现
5. 交叉验证 → 验证关键结论
6. 报告生成 → 输出综合报告
```

## 研究类型

| 类型 | 参数 | 适用场景 |
|------|------|----------|
| 探索性 | `--explore` | 新领域调研 |
| 验证性 | `--verify` | 假设验证 |
| 对比性 | `--compare` | 方案对比 |
| 根因性 | `--root-cause` | 问题诊断 |

## 与其他命令的区别

| 命令 | 用途 | 输出 |
|------|------|------|
| `/yanjiu` | 深度研究 | 研究报告 |
| `/shensou` | 代码搜索 | 搜索结果 |
| `/wukong` | 快速探索 | 定位结果 |

## 提示

- 课题越具体，研究越精准
- 复杂课题建议使用 `--thorough` 模式
- 研究报告会包含置信度标记
- 分歧发现会单独列出供决策

# Code Exploration Expert

`/explore` 是 `/wukong` (悟空) 的英文别名，专注于快速代码探索和定位。

## 使用方式

```bash
/explore [要找的内容]
```

## 示例

```bash
/explore 用户认证相关的代码
/explore 这个报错来自哪里
/explore 数据库连接配置在哪
/explore 找到处理支付的函数
```

- 快速代码定位
- 调用链追踪
- 依赖关系分析
- 模式识别
- 跨文件搜索

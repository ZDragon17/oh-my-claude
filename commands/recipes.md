# 场景指南 (Recipes)

按工作流程组织的使用场景指南，告诉你"我想做X"应该怎么做。

---

## 使用方式

```
/recipes [场景关键词]
```

无参数显示所有场景分类。

---

## 📚 场景分类

### 🚀 功能开发

#### 从零实现一个功能
```
/yishan 实现[功能描述]
```
愚公会自动分解任务、持续执行直到完成。

#### 快速实现一小段代码
```
/luban 实现[具体代码需求]
```
鲁班精工巧匠，适合精细代码实现。

## 🎯 常见工作流

### 完整功能开发流程
```
1. /libai 分析需求            # 理解需求
2. /zhuge 设计方案            # 技术设计
3. /yishan 实现功能          # 编码实现
4. /baozheng 编写测试        # 测试覆盖
5. /weizheng 代码审查        # 质量把关
6. /simaqian 编写文档        # 文档完善
```

### 快速 Bug 修复流程
```
1. /bianque [错误信息]       # 诊断问题
2. /wukong 找相关代码        # 定位代码
3. /luban 修复问题           # 实施修复
4. /baozheng 补充测试        # 防止回归
```

### 性能优化流程
```
1. /sunzi 分析性能           # 找出瓶颈
2. /yishan 实施优化          # 优化代码
3. /sunzi 验证效果           # 确认提升
```

### 代码重构流程
```
1. /weizheng 审查代码        # 发现问题
2. /laozi 简化设计           # 提出方案
3. /yishan 实施重构          # 执行重构
4. /baozheng 确保测试通过    # 质量保证
```

# Agent 发现中心 (Agent Discovery)

快速查看所有可用的 Agent 专家及其专长。

---

## 使用方式

```
/agents [分类关键词]
```

无参数显示所有 Agent 分类视图。

## Agent 详情查看

查看单个 Agent 的详细信息：

```
/agents 扁鹊
```

输出：
```text

  • 错误信息分析
  • 问题根因定位
  • 修复方案设计
  • 预防建议

📖 使用示例:
  /bianque TypeError: Cannot read property 'name' of undefined
  /bianque 分析这个 500 错误
  /bianque 为什么用户登录会失败

🔗 相关命令:
  • /wukong - 代码探索（先找再诊断）
  • /baozheng - 测试验证（诊断后测试）
  • /retry - 重试上次操作
```

## 场景推荐

### 不知道该用谁？

```
/agents 推荐
```

显示智能推荐引导：

```text
🎯 不知道用哪个 Agent？

告诉我你想做什么，我来推荐:

1. 想实现一个功能 → /yishan (愚公持续执行)
2. 遇到报错/Bug → /bianque (扁鹊诊断)
3. 找代码在哪 → /wukong (悟空探索)
4. 审查代码质量 → /weizheng (魏征审查)
5. 设计架构方案 → /zhuge (诸葛顾问)

或者直接用: /do [任务描述]
系统会自动选择合适的 Agent！
```

## 别名

- `/agents` - 主命令
- `/team-list` - 英文别名
- `/专家` - 中文别名
- `/who` - 简写
